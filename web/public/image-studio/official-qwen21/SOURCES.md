# Qwen Image 2.1 official examples

Source: https://qwen.ai/blog?id=qwen-image-2.1
Credit: Qwen Team, 2026-09-20. Original images are unchanged; preview JPEGs are resized for page loading.

The input rectangles in `web/src/features/media-studio/official-examples.json` select only the input tiles from examples 15-17. Their result region is never an input. Examples 18/20 are annotated inputs; 22/23 are the original/mask pair. Prompts are trial instructions based on the demonstrations, not claimed exact official generation parameters. These third-party example images remain attributed to the Qwen Team; the application's code license does not relicense them.
