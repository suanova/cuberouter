# 订阅管理

订阅管理用于创建和管理订阅套餐，用户购买订阅后可获得一定期限内的服务权益，包括额度、用户组升级等特权。

使用管理员账号登录后，直接访问 `/console/subscription`（管理员视角与用户购买界面不同）。

## 订阅方案配置

### 基本信息

![创建订阅套餐弹窗](/imgs/sub-create.png)

| 字段 | 必填 | 说明 |
|------|:----:|------|
| **方案标题** | ✓ | 订阅方案的显示名称，如「月度会员」、「年度会员」 |
| **方案副标题** | | 补充描述信息，如「适合个人用户」 |
| **价格金额** | ✓ | 订阅价格 |
| **货币类型** | ✓ | 价格的货币单位，默认 USD |
| **启用状态** | | 是否启用该方案 |

::: tip 命名建议
- **简洁明了**：如「月度基础版」、「年度专业版」
- **突出价值**：如「无限畅享月卡」、「尊享年度会员」
- **统一风格**：保持所有方案命名风格一致
:::

### 有效期设置

订阅方案支持多种有效期单位：

| 单位 | 说明 | 适用场景 |
|------|------|----------|
| **小时** | 按小时计费 | 临时体验、短期试用 |
| **日** | 按天计费 | 短期活动、体验套餐 |
| **月** | 按月计费 | 标准订阅周期 |
| **年** | 按年计费 | 长期会员、优惠套餐 |
| **自定义** | 自定义秒数 | 特殊周期需求 |

**配置示例**：

| 方案 | 有效期单位 | 数值 | 实际有效期 |
|------|:----------:|:----:|:----------:|
| 体验版 | 日 | 3 | 3 天 |
| 月度会员 | 月 | 1 | 30 天 |
| 季度会员 | 月 | 3 | 90 天 |
| 年度会员 | 年 | 1 | 365 天 |

::: warning 有效期计算
- 月按 30 天计算
- 年按 365 天计算
- 自定义时直接输入秒数（如 86400 = 1 天）
:::

### 额度设置

额度是用户使用 AI 服务的计量单位，订阅方案可包含一定额度供用户使用。

| 字段 | 说明 |
|------|------|
| **总额度** | 订阅包含的总额度，0 表示不限制 |
| **额度重置周期** | 额度重置的时间间隔 |

**重置周期选项**：

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| **不重置** | 额度用完为止，不自动恢复 | 一次性额度包 |
| **每天** | 每日 00:00 重置额度 | 高频使用场景 |
| **每周** | 每周一重置额度 | 周期性需求 |
| **每月** | 每月 1 日重置额度 | 标准订阅模式 |
| **自定义** | 指定间隔秒数重置 | 特殊需求 |

::: info 额度重置行为
- 重置时额度恢复到初始值，不是累加
- 用户未用完的额度不会累积
- 重置时间基于服务器时区
:::

### 用户组升级

订阅方案可以配置购买后自动升级用户组：

| 设置 | 说明 |
|------|------|
| **升级分组** | 购买后自动升级到的用户组名称 |
| **留空** | 不升级用户组，保持原用户组 |

::: tip 用户组与渠道权限
用户组决定了用户可以访问哪些渠道。通过订阅升级用户组，可以实现：
- 普通用户 → VIP 用户（解锁高级模型）
- 体验用户 → 正式用户（解锁更多功能）
:::

### 购买限制

| 字段 | 说明 |
|------|------|
| **用户购买上限** | 单个用户最多可购买的次数，0 表示不限制 |

**应用场景**：

| 上限设置 | 适用场景 |
|----------|----------|
| 0（不限） | 标准方案，可多次购买延长有效期 |
| 1 | 限时优惠、新人专享 |
| N | 限制购买次数的促销活动 |

## 支付集成

订阅方案支持对接多种支付平台，实现自动化订阅购买。支付平台的 API 密钥配置见 [系统设置 - 支付设置](../system/index#支付设置)。

### Stripe 集成

Stripe 是国际主流支付平台，支持信用卡等多种支付方式。

**配置步骤**：

1. 在 Stripe 后台创建产品和价格
2. 获取 Price ID（格式：`price_xxxxx`）
3. 在订阅方案中填写 **Stripe Price ID**
4. 确保已在系统设置中配置 Stripe API 密钥

::: details Stripe Price ID 获取方式
1. 登录 [Stripe Dashboard](https://dashboard.stripe.com/)
2. 进入 Products 页面
3. 选择对应产品
4. 在 Pricing 区域找到 Price ID
:::

### 其他支付方式

平台还支持 **EPay（易支付）** 等聚合支付方式，具体配置方法见 [系统设置 - 支付设置](../system/index#支付设置)。

::: warning 支付配置顺序
1. 先在系统设置中完成支付平台的 API 配置
2. 再在订阅方案中关联对应的价格/产品 ID
3. 最后进行测试支付验证配置正确性
:::

## 操作指南

### 创建订阅方案

1. 在订阅管理页点击「创建套餐」按钮，弹出创建弹窗
2. 填写方案基本信息
   - 方案标题和副标题
   - 价格金额和货币类型
3. 配置有效期
   - 选择有效期单位
   - 设置有效期数值
4. 配置额度
   - 设置总额度
   - 选择重置周期
5. 配置其他选项
   - 用户组升级
   - 购买限制
   - 支付集成 ID
6. 点击「提交」，套餐创建完成并默认处于下架状态

### 上架 / 下架套餐

1. 在套餐列表中找到目标套餐，点击右侧「上架」或「下架」按钮

![套餐上架/下架操作](/imgs/sub-publish.png)

2. 上架后用户在订阅页可看到并购买该套餐；下架后套餐对用户不可见，但已购买的订阅不受影响

### 编辑订阅方案

1. 在方案列表中找到目标方案
2. 点击 **编辑** 按钮
3. 修改需要更新的配置
4. 点击 **保存** 确认修改

::: warning 修改影响
- 修改方案配置后，**新购买**的用户使用新配置
- **已购买**的用户不受影响，继续使用原配置
- 如需调整已购买用户的权益，需通过用户管理手动处理
:::

### 排序管理

- 设置方案的排序值，**数值越大越靠前**
- 调整后用户端按排序值显示方案列表
- 建议将推荐方案排序值设高

**排序建议**：

| 方案 | 排序值 | 显示位置 |
|------|:------:|:--------:|
| 年度会员（推荐） | 100 | 第 1 位 |
| 季度会员 | 50 | 第 2 位 |
| 月度会员 | 10 | 第 3 位 |
| 体验版 | 1 | 第 4 位 |

## 用户订阅管理

### 管理员视角

管理员可以在用户管理页面查看用户的订阅状态：

| 状态 | 说明 |
|------|------|
| 🟢 **活跃订阅** | 当前有效的订阅 |
| ⚪ **过期订阅** | 已过期的订阅历史 |

### 为用户手动开通订阅

1. 在订阅管理页点击「手动绑定」按钮
2. 输入目标用户名或邮箱，选择要开通的套餐
3. 点击「确认」，系统为该用户创建订阅记录，立即生效

### 用户端功能

用户在订阅管理页面可以：

| 功能 | 说明 |
|------|------|
| 查看方案 | 浏览可用的订阅方案 |
| 购买订阅 | 选择方案并完成支付 |
| 查看状态 | 查看当前订阅和有效期 |
| 额度查询 | 查看剩余额度使用情况 |

## 常见问题

::: details 如何设置试用期？
创建一个价格为 0 的体验方案，设置较短有效期（如 7 天），并设置购买上限为 1。
:::

::: details 用户订阅到期后会发生什么？
- 用户组会恢复到默认组（如果订阅包含升级）
- 额度不再重置，剩余额度可继续使用
- 用户可以续订或购买新方案
:::

::: details 如何实现订阅续费？
用户在订阅有效期内再次购买相同方案，有效期会自动延长。
:::

## 注意事项

::: warning 价格设置
- 确保价格金额与支付平台配置一致
- 货币类型需与支付平台支持币种匹配
- 修改价格后需同步更新支付平台的价格 ID
:::

::: tip 额度规划
- 根据模型定价计算合理额度
- 设置重置周期时考虑用户使用习惯
- 提供多种额度档位满足不同需求
:::

::: danger 方案禁用影响
- 禁用方案后，**新用户无法购买**
- 已购买用户**不受影响**，权益继续生效
- 如需彻底下线，建议设置过渡期通知用户
:::
