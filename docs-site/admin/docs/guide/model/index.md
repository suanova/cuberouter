# 模型管理

模型管理用于管理平台所有模型的元数据和定价，配置「模型广场」的展示效果，包括模型信息、展示状态、分组权限等。使用管理员账号登录后，左侧导航点击「模型」，或直接访问 `/console/models`。

::: warning 重要说明
本页面配置**仅影响模型广场的展示效果**，不会影响模型的实际调用与路由。

若需配置真实的模型调用行为（如 API 接入、负载均衡、故障转移等），请前往 [渠道管理](../channel/index) 进行设置。
:::

## 功能概览

![模型列表页](/imgs/model-list.png)

模型列表展示平台所有已配置的模型，包含模型名称、类型、输入/输出定价、所属厂商等信息。

模型管理页面提供以下功能：

| 功能 | 说明 |
|------|------|
| **模型列表** | 查看所有已配置的模型 |
| **添加模型** | 创建新的模型展示配置 |
| **编辑模型** | 修改模型展示信息 |
| **启用/禁用** | 控制模型在模型广场的可见性 |
| **批量操作** | 批量修改模型的展示配置 |

## 展示配置与实际调用的区别

| 配置项 | 模型管理（展示） | 渠道管理（调用） |
|--------|------------------|------------------|
| 模型可用性 | 控制模型广场是否显示 | 控制实际能否调用 |
| 用户权限 | 控制谁能看到模型 | 控制谁能调用模型 |
| 模型定价 | 展示给用户的价格信息 | 实际计费扣款依据 |
| 渠道绑定 | 只读展示 | 实际配置 |

::: tip 配置优先级
实际调用以**渠道管理**配置为准。模型广场的展示配置仅影响用户界面。
:::

## 模型配置

### 基本信息

| 字段 | 必填 | 说明 |
|------|:----:|------|
| **模型 ID** | ✓ | 模型的唯一标识符，如 `gpt-4-turbo` |
| **模型名称** | ✓ | 模型在模型广场的显示名称 |
| **供应商** | ✓ | 模型所属的供应商分类 |
| **模型图标** | | 模型在界面中显示的图标 |

::: info 模型 ID 说明
模型 ID 需要与渠道管理中配置的模型名称一致，否则用户在模型广场选择后无法正常调用。
:::

### 只读展示信息

以下信息从**渠道管理**自动读取，在模型管理页面仅作展示，不可编辑：

| 字段 | 来源 | 说明 |
|------|------|------|
| **已绑定渠道** | 渠道管理 | 显示哪些渠道配置了该模型 |
| **可用分组** | 渠道管理 | 显示渠道中配置的用户组权限 |
| **计费类型** | 渠道管理 | 显示模型的计费方式 |

::: warning 如何修改这些信息？
这些信息由渠道管理决定，如需修改：
1. 前往 [渠道管理](../channel/index)
2. 找到对应的渠道
3. 修改渠道中的模型列表或用户组配置
:::

### 展示权限设置

| 字段 | 说明 |
|------|------|
| **启用分组** | 控制哪些用户组可以在模型广场看到该模型 |
| **标签** | 模型的分类标签，便于用户筛选 |

**启用分组选项**：

| 分组 | 说明 |
|------|------|
| **default** | 所有用户可见 |
| **vip** | 仅 VIP 用户可见 |
| **自定义组** | 指定用户组可见 |

::: tip 展示权限 vs 调用权限
- **展示权限**：控制模型广场是否显示该模型
- **调用权限**：由渠道管理中的用户组设置决定

两者建议保持一致，避免用户看到模型但无法调用。
:::

### 定价展示配置

| 字段 | 说明 |
|------|------|
| **计费类型** | 展示给用户的计费方式说明 |
| **输入价格** | 输入 token 的价格展示比例 |
| **输出价格** | 输出 token 的价格展示比例 |
| **最大上下文** | 模型的最大上下文长度展示 |

::: warning 定价说明
此处配置的价格信息仅用于**模型广场展示**，帮助用户了解不同模型的价格差异。

实际扣费依据渠道管理中的配置或系统全局定价设置。
:::

### 端点配置

端点配置定义模型支持的功能类型，用于前端功能展示：

```json
{
  "chat": "/v1/chat/completions",
  "embeddings": "/v1/embeddings",
  "completions": "/v1/completions"
}
```

## 计费类型说明

模型支持两种计费方式：

| 类型 | 说明 | 展示效果 |
|------|------|----------|
| **按次计费** | 每次请求固定消耗额度 | 适合聊天场景 |
| **按量计费** | 根据 token 数量消耗额度 | 适合长文本处理 |

### 价格比例

价格比例用于展示不同模型的相对成本：

| 模型 | 输入价格 | 输出价格 | 说明 |
|------|:--------:|:--------:|------|
| GPT-3.5 | 1 | 1 | 基准模型 |
| GPT-4 | 30 | 60 | 输入为基准 30 倍 |
| Claude 3 | 15 | 75 | 输入为基准 15 倍 |

## 模型广场展示效果

### 启用/禁用模型

| 状态 | 模型广场效果 |
|------|--------------|
| 🟢 **已启用** | 模型在模型广场可见 |
| 🔴 **已禁用** | 模型在模型广场不显示 |

### 标签分类

标签用于在模型广场中分类展示模型：

| 标签类型 | 示例 |
|----------|------|
| **按能力** | `对话`、`代码`、`绘图`、`嵌入` |
| **按特点** | `长上下文`、`多模态`、`高速` |
| **按用途** | `通用`、`专业`、`企业` |

### 批量启用

模型管理支持批量操作：

1. 选中多个模型
2. 选择批量操作类型
3. 设置目标用户组
4. 确认操作

## 添加 / 编辑模型

1. 点击「添加模型」按钮，或点击已有模型右侧的「编辑」按钮

![添加/编辑模型弹窗](/imgs/model-edit.png)

2. 填写模型信息：
   - 模型 ID（与渠道中配置一致）
   - 模型名称与供应商
   - 输入价格、输出价格
3. 配置展示权限（启用分组、分类标签）
4. 点击「保存」完成配置

### 批量修改展示分组

1. 选中需要修改的模型
2. 点击 **批量修改分组**
3. 选择目标分组
4. 确认修改

---

## 同步上游模型

同步功能可从各服务商获取最新模型列表，预览变更后再决定是否应用。

1. 在模型管理页点击「同步上游」按钮
2. 系统请求上游服务商的模型列表，弹出预览弹窗

![同步上游模型预览弹窗](/imgs/model-sync-preview.png)

3. 预览弹窗中分别列出「新增」「变更」「删除」的模型
4. 确认无误后点击「应用」，模型列表更新完成

![同步完成后的模型列表](/imgs/model-synced.png)

::: tip 同步建议
建议在渠道配置完成后，使用模型同步功能快速创建模型广场的展示配置。
:::

## 注意事项

::: warning 模型 ID 一致性
模型管理中的模型 ID 必须与渠道管理中的模型名称一致，否则：
- 用户在模型广场选择模型后可能无法调用
- 渠道绑定的展示信息无法正确显示
:::

::: tip 展示与调用配置建议
1. 先在渠道管理配置模型调用
2. 再在模型管理配置展示效果
3. 确保两边配置的用户组一致
:::

::: info 只读字段
已绑定渠道、可用分组、计费类型等字段从渠道管理读取，仅作展示。如需修改请前往渠道管理。
:::
