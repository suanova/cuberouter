# 用户管理

用户管理用于管理系统中的所有用户账户，包括用户信息查看、权限管理、额度调整、订阅管理等。通过用户管理，管理员可以全面掌控平台用户的状态和权益。

使用管理员账号登录后，左侧导航点击「用户」，或直接访问 `/console/user`。

## 功能概览

![用户列表页](/imgs/user-list.png)

用户列表展示平台所有注册用户，包含用户名、邮箱、角色、分组、配额余额、状态等信息。

用户管理页面提供以下功能：

| 功能 | 说明 |
|------|------|
| **用户列表** | 查看所有用户及基本信息 |
| **搜索用户** | 按用户名、邮箱等搜索 |
| **编辑用户** | 修改用户信息 |
| **额度调整** | 增减或设置用户额度 |
| **订阅管理** | 查看和调整用户订阅 |
| **启用/禁用** | 控制用户账户状态 |
| **删除用户** | 移除用户账户 |

## 用户信息

### 基本字段

| 字段 | 说明 |
|------|------|
| **ID** | 用户的唯一标识，系统自动生成 |
| **用户名** | 用户的登录名，注册时设置 |
| **显示名称** | 用户的显示名称，可修改 |
| **邮箱** | 用户的邮箱地址 |
| **用户组** | 用户所属的用户组，决定渠道访问权限 |
| **角色** | 用户的权限角色，决定管理权限 |
| **状态** | 账户当前状态 |

### 角色类型

| 角色 | 值 | 权限说明 |
|------|:---:|----------|
| **访客** | 0 | 游客身份，仅可浏览公开页面 |
| **普通用户** | 1 | 基础使用权限，可使用 API |
| **运营** | 5 | 可查看/导出自己邀请的用户，只读运营视图 |
| **管理员** | 10 | 管理后台访问权限，可管理普通用户 |
| **超级管理员** | 100 | 完全管理权限，可管理所有用户和系统设置 |

::: warning 权限分配
- 超级管理员角色应严格控制数量
- 管理员角色按需分配
- 运营角色为只读运营视图，无法管理其他用户
- 普通用户为默认角色
:::

### 状态类型

| 状态 | 图标 | 说明 | 影响 |
|------|:----:|------|------|
| **已启用** | 🟢 | 账户正常 | 可正常使用所有功能 |
| **已禁用** | 🔴 | 账户被禁用 | 无法登录，API 请求被拒绝 |
| **已注销** | ⚪ | 账户已注销 | 账户已删除相关数据 |

## 额度管理

### 额度字段说明

![编辑用户弹窗](/imgs/user-edit.png)

| 字段 | 说明 |
|------|------|
| **总额度** | 用户拥有的总额度（含已使用） |
| **已用额度** | 用户已消耗的额度 |
| **剩余额度** | 用户剩余可用额度 |
| **请求次数** | 用户的 API 请求累计次数 |

### 额度调整

管理员可以灵活调整用户的额度：

**操作步骤**：
1. 在用户列表中找到目标用户
2. 点击 **调整额度** 按钮
3. 选择调整方式
4. 输入调整数值
5. 确认调整

**调整方式**：

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **增加额度** | 在现有额度基础上增加指定数量 | 奖励、补偿、手动充值 |
| **减少额度** | 在现有额度基础上减少指定数量 | 违规处罚、错误修正 |
| **设置额度** | 直接设置为指定值 | 初始化、重置额度 |

::: tip 额度调整记录
建议在调整额度时通过备注字段记录原因，便于后续审计和查询。
:::

## 用户组管理

用户组用于控制用户可访问的渠道和模型，是权限管理的核心机制。详细说明见 [分组管理](../group/index)。

### 修改用户组

1. 在用户列表中找到目标用户
2. 点击 **编辑** 按钮
3. 修改 **用户组** 字段
4. 保存更改

::: warning 用户组变更影响
修改用户组会立即生效，影响：
- 用户可访问的渠道列表
- 用户在模型广场可见的模型
- 用户可调用的模型范围
:::

## 操作指南

### 查看用户详情

1. 在用户列表中找到目标用户
2. 点击用户名或 **查看** 按钮
3. 查看用户的详细信息：
   - 基本信息
   - 额度使用情况
   - 请求统计
   - 登录记录
   - 订阅状态

### 编辑用户

1. 在用户列表中找到目标用户，点击右侧「编辑」按钮，弹出编辑弹窗

![编辑用户弹窗](/imgs/user-edit.png)

2. 修改需要更新的信息：

| 字段 | 说明 |
|------|------|
| **角色** | 普通用户 / 运营 / 管理员，修改后立即生效 |
| **分组** | 指定用户所属的渠道分组 |
| **配额余额** | 直接设置用户的配额数值 |
| **状态** | 启用或禁用账号，禁用后该用户无法登录 |

::: info 超级管理员说明
**超级管理员（Root）** 不在此弹窗的分配范围内：Root 账号不可被其他管理员分配或降级，仅可自行管理。
:::

3. 点击 **保存** 确认修改

### 启用/禁用用户

1. 在用户列表中找到目标用户
2. 点击状态开关或 **禁用/启用** 按钮
3. 确认操作

::: warning 禁用影响
用户被禁用后：
- 立即无法登录系统
- API 请求会被拒绝
- 现有 Token 失效
- 订阅暂停计费（如适用）
:::

### 删除用户

1. 在用户列表中找到目标用户
2. 点击 **删除** 按钮
3. 确认删除操作

::: danger 删除警告
删除用户将**永久清除**该用户的所有数据：
- 账户信息
- 额度记录
- 请求日志
- 订阅记录
- 其他关联数据

此操作**不可恢复**，请谨慎操作！
:::

## 搜索与筛选

### 搜索功能

1. 在用户列表顶部找到搜索框
2. 输入用户名或邮箱关键词，列表实时过滤

![搜索框输入关键词后的过滤结果](/imgs/user-search.png)

支持按以下字段搜索用户：

| 搜索字段 | 说明 |
|----------|------|
| 用户名 | 精确或模糊匹配 |
| 邮箱地址 | 精确或模糊匹配 |
| 用户 ID | 精确匹配 |

### 筛选功能

支持按以下条件筛选：

| 筛选条件 | 选项 |
|----------|------|
| 用户角色 | 普通用户 / 运营 / 管理员 / 超级管理员 |
| 用户组 | default / vip / 自定义组 |
| 账户状态 | 已启用 / 已禁用 / 已注销 |

## 邀请系统

用户可以通过邀请链接邀请新用户：

| 字段 | 说明 |
|------|------|
| **邀请码** | 用户的专属邀请码，可用于生成邀请链接 |
| **邀请人数** | 成功邀请的用户数量 |
| **邀请额度** | 通过邀请获得的奖励额度 |

### 邀请奖励机制

```text
邀请人分享邀请链接 → 新用户注册 → 双方获得奖励额度
```

::: tip 邀请奖励配置
邀请奖励额度在 [系统设置 - 运营设置](../system/index#运营设置) 中配置：
- 邀请人奖励额度
- 被邀请人奖励额度
:::

## 常见操作场景

### 用户充值/补偿

1. 找到目标用户
2. 点击 **调整额度** → 选择 **增加额度**
3. 输入额度数量
4. 在备注中记录原因
5. 确认调整

### 用户升级 VIP

1. 找到目标用户
2. 点击 **编辑**
3. 将用户组改为 `vip`
4. 保存更改

### 处理违规用户

1. 找到目标用户
2. 点击 **禁用** 按钮
3. 在备注中记录违规原因
4. 确认禁用

### 批量操作

对于大量用户的管理需求：
- 使用搜索和筛选定位目标用户群
- 导出用户列表进行批量处理
- 通过 API 实现自动化管理

## 注意事项

::: warning 权限管理
- 谨慎分配管理员和超级管理员权限
- 定期审核管理员账户
- 离职员工及时撤销权限或禁用账户
:::

::: tip 额度管理建议
- 额度调整时填写备注记录原因
- 大额调整建议通过订阅系统而非手动调整
- 定期检查异常额度变化
:::

::: info 用户数据安全
- 用户删除操作不可逆
- 删除前确保已备份必要数据
- 敏感信息变更应有审计记录
:::
