# 日志与统计

日志与统计用于查看全平台 API 调用记录和消耗统计，支持按用户、模型、渠道等多维度分析。使用管理员账号登录后，左侧导航点击「日志」，或直接访问 `/console/log`。

## 快速导航

| 操作 | 说明 |
|------|------|
| [日志列表](#功能概览) | 查看全平台调用记录 |
| [搜索与过滤](#搜索与过滤) | 多维度筛选日志 |
| [日志统计面板](#日志统计面板) | 全平台调用量汇总 |
| [全平台消耗趋势](#全平台消耗趋势) | 消耗趋势与用户分布 |

## 功能概览

![全平台日志列表](/imgs/admin-log.png)

管理员视角的日志列表比普通用户多出「用户名」和「渠道名」两列，可查看所有用户的调用记录。

日志列表展示每次 API 调用的详细信息：

| 字段 | 说明 |
|------|------|
| **用户** | 调用者用户名（管理员可见全部用户） |
| **渠道** | 实际处理请求的渠道（管理员可见） |
| **令牌** | 调用所使用的 API 令牌 |
| **模型** | 请求的模型名称 |
| **分组** | 令牌所属的渠道分组 |
| **提示词/补全 token** | 输入与输出 token 数量 |
| **消耗** | 本次调用消耗的配额 |
| **响应时间** | 请求耗时 |
| **状态** | 请求结果（成功 / 失败及原因） |

## 搜索与过滤

1. 在日志页顶部点击「筛选」按钮，展开过滤条件区域
2. 可设置以下过滤条件：
   - **时间范围**：选择开始和结束日期
   - **用户名**：输入用户名关键词
   - **模型**：输入模型名称关键词
   - **渠道**：选择特定渠道
   - **令牌名**：输入令牌名称
3. 点击「查询」，列表刷新显示过滤结果

![日志筛选条件展开状态](/imgs/admin-log-filter.png)

## 日志统计面板

在日志页顶部查看统计汇总区域，展示全平台的调用量汇总数据。

![日志统计面板（总调用次数、总消耗配额等）](/imgs/admin-log-stat.png)

统计面板包含以下指标：

| 指标 | 说明 |
|------|------|
| **总调用次数** | 时间范围内的 API 调用总量 |
| **总消耗配额** | 时间范围内的配额消耗总量 |
| **总 Token 数** | 输入与输出 Token 总和 |
| **成功率** | 成功请求占比 |

## 全平台消耗趋势

1. 左侧导航点击「数据看板」，或直接访问 `/console`（管理员视角）

![全平台消耗趋势图](/imgs/admin-dashboard.png)

2. 管理员数据看板展示全平台的消耗趋势折线图，以及各用户的消耗占比分布
3. 将鼠标悬停在图表上可查看具体日期的详细数据

## 注意事项

::: tip 日志运维建议
- 日志数据量较大时建议定期归档或清理
- 结合 [系统设置 - 其他设置](../system/index#其他设置) 中的日志保留天数配置，控制存储占用
- 排查问题时优先使用筛选功能定位目标请求
:::

::: warning 日志可见性
- 普通用户只能查看自己的调用记录
- 管理员可查看全平台日志（含用户名、渠道名列）
- 日志中的敏感信息请按合规要求管理
:::
