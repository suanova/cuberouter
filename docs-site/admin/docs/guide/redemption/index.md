# 兑换码管理

兑换码管理用于批量生成和管理配额兑换码，用于活动赠送或用户充值。通过兑换码，管理员可以灵活地进行营销推广、用户激励等活动。

使用管理员账号登录后，左侧导航点击「兑换码」，或直接访问 `/console/redemption`。

::: warning 合规提示
兑换码使用应符合授权范围、平台规则和所在地法律法规要求。兑换码仅用于内部测试、授权客户交付、活动赠送或账务调整。
:::

## 兑换码配置

### 基本信息

![生成兑换码弹窗](/imgs/redemption-create.png)

| 字段 | 必填 | 说明 |
|------|:----:|------|
| **名称** | ✓ | 兑换码的标识名称，便于识别批次 |
| **额度** | ✓ | 兑换码包含的额度值 |
| **数量** | ✓ | 生成兑换码的数量 |
| **过期时间** | | 兑换码的有效期限 |

### 过期时间设置

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| **永不过期** | 兑换码永久有效 | 长期活动、备用额度 |
| **指定时间** | 设置具体的过期时间 | 限时活动、促销优惠 |

::: warning 过期处理
过期后的兑换码将无法使用，状态显示为「已过期」。过期兑换码可在列表中筛选查看，建议定期清理。
:::

### 批量生成规则

设置数量后，系统会生成相应数量的兑换码：

- 每个兑换码拥有**唯一的兑换码 Key**
- 同一批次生成的兑换码共享相同的名称、额度和过期时间
- 兑换码 Key 为系统自动生成的随机字符串

**示例**：

| 名称 | 额度 | 数量 | 生成结果 |
|------|:----:|:----:|----------|
| 新人礼包 | 10,000 | 50 | 生成 50 个 Key，每个 10,000 额度 |
| 活动奖励 | 5,000 | 100 | 生成 100 个 Key，每个 5,000 额度 |

## 兑换码状态

| 状态 | 图标 | 说明 | 可操作 |
|------|:----:|------|:------:|
| **未使用** | 🟢 | 兑换码可用，等待兑换 | 编辑、删除、复制 |
| **已使用** | 🔵 | 兑换码已被使用 | 查看、删除 |
| **已过期** | 🔴 | 兑换码已过期，无法使用 | 删除 |

::: tip 状态自动变更
- 用户成功兑换后，状态自动变更为「已使用」，已使用的兑换码无法恢复
- 到达过期时间后，状态自动变更为「已过期」，可通过修改过期时间重新激活
:::

## 操作指南

### 创建兑换码

1. 在兑换码列表页点击「生成兑换码」按钮，弹出生成弹窗
2. 填写兑换码信息：
   - **名称**：便于识别的批次名称
   - **面值**：每张兑换码对应的配额数量
   - **数量**：本次生成的兑换码张数
3. 点击「生成」，系统批量创建兑换码并显示在列表中

![生成完成后的兑换码列表](/imgs/redemption-created.png)

::: tip 命名建议
使用有意义的名称便于后期管理：
- 按活动命名：`双十一活动`、`新用户福利`
- 按渠道命名：`官网注册`、`微信推广`
- 按等级命名：`体验额度`、`VIP福利`
:::

### 编辑兑换码

1. 在兑换码列表中找到目标兑换码
2. 点击 **编辑** 按钮
3. 修改需要更新的配置：
   - 名称
   - 额度
   - 过期时间
4. 点击 **保存** 确认修改

::: warning 编辑限制
- **已使用**的兑换码无法编辑
- **已过期**的兑换码可以修改过期时间重新激活
:::

### 删除兑换码

1. 在兑换码列表中找到目标兑换码
2. 点击 **删除** 按钮
3. 确认删除操作

::: danger 删除警告
删除操作**不可恢复**，请谨慎操作。建议：
- 已使用的兑换码可保留一段时间作为记录
- 过期的兑换码可定期批量清理
:::

### 复制 / 导出兑换码

- 点击 **复制** 按钮，兑换码 Key 将复制到剪贴板
- 点击「导出」按钮，将兑换码导出为文件，方便批量分发

## 用户兑换流程

### 用户端操作

用户可以通过以下步骤兑换额度：

1. 登录账户
2. 进入 **个人中心** → **兑换中心**
3. 输入兑换码 Key
4. 点击 **兑换** 按钮
5. 系统验证并发放额度

### 兑换规则

| 规则 | 说明 |
|------|------|
| 单次使用 | 每个兑换码只能使用一次 |
| 不可重复 | 已使用的兑换码无法再次使用 |
| 有效期限制 | 过期的兑换码无法使用 |
| 即时到账 | 兑换成功后额度立即到账 |

### 兑换失败情况

| 错误提示 | 原因 | 解决方案 |
|----------|------|----------|
| 兑换码不存在 | 输入的 Key 有误 | 检查是否复制正确 |
| 兑换码已使用 | 该码已被兑换 | 使用其他兑换码 |
| 兑换码已过期 | 已超过有效期 | 联系管理员获取新码 |

## 使用场景

### 营销推广

| 场景 | 配置建议 |
|------|----------|
| 新用户注册 | 名称：`新用户福利`，额度适中，数量大 |
| 促销活动 | 设置过期时间，配合活动周期 |
| 合作推广 | 按渠道命名，便于追踪效果 |

### 用户激励

| 场景 | 配置建议 |
|------|----------|
| 邀请奖励 | 名称：`邀请奖励`，额度较高 |
| 活动奖品 | 限量生成，设置过期时间 |
| 补偿发放 | 单独生成，备注原因 |

### 测试用途

| 场景 | 配置建议 |
|------|----------|
| 功能测试 | 名称：`测试`，额度小 |

## 注意事项

::: warning 安全保管
兑换码 Key 具有价值，请妥善保管：
- 不要在公开场合分享兑换码
- 发放时使用私密渠道
- 定期检查未使用兑换码的状态
:::

::: tip 批量管理建议
- 使用有意义的命名便于识别
- 定期清理已使用和过期的兑换码
- 大量发放时建议分批次生成
:::

::: info 额度计算
兑换码额度与系统额度单位一致。用户兑换后，额度会**累加**到用户当前余额，而不是覆盖。
:::
