# 分组管理

分组用于隔离不同用户的渠道访问权限和计费倍率，是权限管理的核心机制。不同分组的用户只能使用分配给该分组的渠道。使用管理员账号登录后，在系统设置或管理面板中找到「分组」入口。

分组列表展示平台所有已配置的分组名称。用户和令牌均可指定所属分组，渠道也可限定只对特定分组开放。

## 分组的使用方式

- **用户分组**：在用户管理页编辑用户时，可为用户指定所属分组
- **令牌分组**：创建令牌时可指定该令牌使用的渠道分组
- **渠道分组**：添加渠道时可在「分组」字段填写允许访问该渠道的分组名称

::: info 令牌自动分组
令牌分组设为 `auto` 时，系统按优先级顺序自动选择一个可用分组，适合需要跨分组容灾的场景。
:::

## 预置用户组

| 用户组 | 说明 | 典型用途 |
|--------|------|----------|
| **default** | 默认用户组 | 所有新注册用户的初始组，基础权限 |
| **vip** | VIP 用户组 | 付费用户或特殊用户，高级权限 |
| **自定义组** | 管理员创建 | 按业务需求细分权限 |

## 分组与渠道权限

用户组决定了用户可以访问哪些渠道：

```text
用户组 ──关联──▶ 渠道 ──包含──▶ 模型
```

::: info 权限逻辑
1. 渠道配置中指定允许访问的用户组
2. 用户所属用户组与渠道用户组匹配时
3. 用户才能通过该渠道调用模型

例如：
- 用户 A 属于 `default` 组
- 渠道 X 配置为 `vip` 组可用
- 用户 A 无法通过渠道 X 调用模型
:::

### 修改用户组

1. 在用户列表中找到目标用户
2. 点击 **编辑** 按钮
3. 修改 **用户组** 字段
4. 保存更改

::: warning 用户组变更影响
修改用户组会立即生效，影响：
- 用户可访问的渠道列表
- 用户在模型广场可见的模型
- 用户可调用的模型范围
:::

## 分组倍率

分组倍率允许为不同用户组设置差异化的计费倍数，实现灵活的定价策略：

```json
{
  "vip": 0.5,
  "premium": 0.8,
  "standard": 1.0,
  "trial": 2.0
}
```

分组倍率与模型倍率叠加计算：

```text
最终消耗 = Token 数量 × 模型倍率 × 分组倍率
```

**分组倍率优先级**：

1. 用户专属倍率：为特定用户设置的个人倍率
2. 分组倍率：用户所属分组的倍率
3. 默认倍率：系统默认倍率（通常为 1.0）

具体配置方法见 [系统设置 - 计费与倍率设置](../system/index#计费与倍率设置)。

## 自动分组设置

控制新用户的默认分组行为：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| **默认使用自动分组** | 是否默认使用自动分组 | 关闭 |
| **自动分组列表** | 自动分组的用户组列表 | `["default"]` |

::: info 自动分组说明
自动分组用于根据特定规则（如邀请码、注册来源等）自动将用户分配到特定用户组。配置后，符合条件的用户会自动加入指定用户组。
:::

## 注意事项

::: warning 权限规划
- 分组权限的变更会影响所有组内用户，变更前先评估影响范围
- 建议为不同业务场景建立独立分组，避免权限混杂
- 定期审查分组的渠道授权，及时清理过期配置
:::
