# 用戶管理

用戶管理用於管理系統中的所有用戶賬戶，包括用戶資訊查看、權限管理、額度調整、訂閱管理等。通過用戶管理，管理員可以全面掌控平臺用戶的狀態和權益。

使用管理員賬號登錄後，左側導航點擊「用戶」，或直接訪問 `/console/user`。

| [額度調整](#額度管理) | 增減用戶額度 |

## 功能概覽

![用戶列表頁](/imgs/user-list.png)

用戶列表展示平臺所有註冊用戶，包含用戶名、郵箱、角色、分組、配額餘額、狀態等資訊。

用戶管理頁面提供以下功能：

| 功能 | 說明 |
|------|------|
| **用戶列表** | 查看所有用戶及基本資訊 |
| **搜索用戶** | 按用戶名、郵箱等搜索 |
| **編輯用戶** | 修改用戶資訊 |
| **額度調整** | 增減或設置用戶額度 |
| **訂閱管理** | 查看和調整用戶訂閱 |
| **啟用/禁用** | 控制用戶賬戶狀態 |
| **刪除用戶** | 移除用戶賬戶 |

## 用戶資訊

### 基本字段

| 字段 | 說明 |
|------|------|
| **ID** | 用戶的唯一標識，系統自動生成 |
| **用戶名** | 用戶的登錄名，註冊時設置 |
| **顯示名稱** | 用戶的顯示名稱，可修改 |
| **郵箱** | 用戶的郵箱地址 |
| **用戶組** | 用戶所屬的用戶組，決定渠道訪問權限 |
| **角色** | 用戶的權限角色，決定管理權限 |
| **狀態** | 賬戶當前狀態 |

### 角色類型

| 角色 | 值 | 權限說明 |
|------|:---:|----------|
| **訪客** | 0 | 遊客身份，僅可瀏覽公開頁面 |
| **普通用戶** | 1 | 基礎使用權限，可使用 API |
| **運營** | 5 | 可查看/導出自己邀請的用戶，只讀運營視圖 |
| **管理員** | 10 | 管理後臺訪問權限，可管理普通用戶 |
| **超級管理員** | 100 | 完全管理權限，可管理所有用戶和系統設置 |

::: warning 權限分配
- 超級管理員角色應嚴格控制數量
- 管理員角色按需分配
- 運營角色為只讀運營視圖，無法管理其他用戶
- 普通用戶為預設角色
:::

### 狀態類型

| 狀態 | 圖標 | 說明 | 影響 |
|------|:----:|------|------|
| **已啟用** | 🟢 | 賬戶正常 | 可正常使用所有功能 |
| **已禁用** | 🔴 | 賬戶被禁用 | 無法登錄，API 請求被拒絕 |
| **已註銷** | ⚪ | 賬戶已註銷 | 賬戶已刪除相關數據 |

## 額度管理

### 額度字段說明

![編輯用戶彈窗](/imgs/user-edit.png)

| 字段 | 說明 |
|------|------|
| **總額度** | 用戶擁有的總額度（含已使用） |
| **已用額度** | 用戶已消耗的額度 |
| **剩餘額度** | 用戶剩餘可用額度 |
| **請求次數** | 用戶的 API 請求累計次數 |

### 額度調整

管理員可以靈活調整用戶的額度：

**操作步驟**：
1. 在用戶列表中找到目標用戶
2. 點擊 **調整額度** 按鈕
3. 選擇調整方式
4. 輸入調整數值
5. 確認調整

**調整方式**：

| 方式 | 說明 | 適用場景 |
|------|------|----------|
| **增加額度** | 在現有額度基礎上增加指定數量 | 獎勵、補償、手動充值 |
| **減少額度** | 在現有額度基礎上減少指定數量 | 違規處罰、錯誤修正 |
| **設置額度** | 直接設置為指定值 | 初始化、重置額度 |

::: tip 額度調整記錄
建議在調整額度時通過備註字段記錄原因，便於後續審計和查詢。
:::

## 用戶組管理

用戶組用於控制用戶可訪問的渠道和模型，是權限管理的核心機制。詳細說明見 [分組管理](../group/index)。

### 修改用戶組

1. 在用戶列表中找到目標用戶
2. 點擊 **編輯** 按鈕
3. 修改 **用戶組** 字段
4. 保存更改

::: warning 用戶組變更影響
修改用戶組會立即生效，影響：
- 用戶可訪問的渠道列表
- 用戶在模型廣場可見的模型
- 用戶可調用的模型範圍
:::

## 操作指南

### 查看用戶詳情

1. 在用戶列表中找到目標用戶
2. 點擊用戶名或 **查看** 按鈕
3. 查看用戶的詳細資訊：
   - 基本資訊
   - 額度使用情況
   - 請求統計
   - 登錄記錄
   - 訂閱狀態

### 編輯用戶

1. 在用戶列表中找到目標用戶，點擊右側「編輯」按鈕，彈出編輯彈窗

![編輯用戶彈窗](/imgs/user-edit.png)

2. 修改需要更新的資訊：

| 字段 | 說明 |
|------|------|
| **角色** | 普通用戶 / 運營 / 管理員，修改後立即生效 |
| **分組** | 指定用戶所屬的渠道分組 |
| **配額餘額** | 直接設置用戶的配額數值 |
| **狀態** | 啟用或禁用賬號，禁用後該用戶無法登錄 |

::: info 超級管理員說明
**超級管理員（Root）** 不在此彈窗的分配範圍內：Root 賬號不可被其他管理員分配或降級，僅可自行管理。
:::

3. 點擊 **保存** 確認修改

### 啟用/禁用用戶

1. 在用戶列表中找到目標用戶
2. 點擊狀態開關或 **禁用/啟用** 按鈕
3. 確認操作

::: warning 禁用影響
用戶被禁用後：
- 立即無法登錄系統
- API 請求會被拒絕
- 現有 Token 失效
- 訂閱暫停計費（如適用）
:::

### 刪除用戶

1. 在用戶列表中找到目標用戶
2. 點擊 **刪除** 按鈕
3. 確認刪除操作

::: danger 刪除警告
刪除用戶將**永久清除**該用戶的所有數據：
- 賬戶資訊
- 額度記錄
- 請求日誌
- 訂閱記錄
- 其他關聯數據

此操作**不可恢復**，請謹慎操作！
:::

## 搜索與篩選

### 搜索功能

1. 在用戶列表頂部找到搜索框
2. 輸入用戶名或郵箱關鍵詞，列表實時過濾

![搜索框輸入關鍵詞後的過濾結果](/imgs/user-search.png)

支援按以下字段搜索用戶：

| 搜索字段 | 說明 |
|----------|------|
| 用戶名 | 精確或模糊匹配 |
| 郵箱地址 | 精確或模糊匹配 |
| 用戶 ID | 精確匹配 |

### 篩選功能

支援按以下條件篩選：

| 篩選條件 | 選項 |
|----------|------|
| 用戶角色 | 普通用戶 / 運營 / 管理員 / 超級管理員 |
| 用戶組 | default / vip / 自定義組 |
| 賬戶狀態 | 已啟用 / 已禁用 / 已註銷 |

## 第三方登錄綁定

用戶資訊中顯示第三方登錄綁定狀態：

| 字段 | 說明 | 綁定條件 |
|------|------|----------|

::: info 第三方登錄配置

:::

## 邀請系統

用戶可以通過邀請鏈接邀請新用戶：

| 字段 | 說明 |
|------|------|
| **邀請碼** | 用戶的專屬邀請碼，可用於生成邀請鏈接 |
| **邀請人數** | 成功邀請的用戶數量 |
| **邀請額度** | 通過邀請獲得的獎勵額度 |

### 邀請獎勵機制

```text
邀請人分享邀請鏈接 → 新用戶註冊 → 雙方獲得獎勵額度
```

::: tip 邀請獎勵配置
邀請獎勵額度在 [系統設置 - 運營設置](../system/index#運營設置) 中配置：
- 邀請人獎勵額度
- 被邀請人獎勵額度
:::

## 常見操作場景

### 用戶充值/補償

1. 找到目標用戶
2. 點擊 **調整額度** → 選擇 **增加額度**
3. 輸入額度數量
4. 在備註中記錄原因
5. 確認調整

### 用戶升級 VIP

1. 找到目標用戶
2. 點擊 **編輯**
3. 將用戶組改為 `vip`
4. 保存更改

### 處理違規用戶

1. 找到目標用戶
2. 點擊 **禁用** 按鈕
3. 在備註中記錄違規原因
4. 確認禁用

### 批量操作

對於大量用戶的管理需求：
- 使用搜索和篩選定位目標用戶羣
- 導出用戶列表進行批量處理
- 通過 API 實現自動化管理

## 注意事項

::: warning 權限管理
- 謹慎分配管理員和超級管理員權限
- 定期審覈管理員賬戶
- 離職員工及時撤銷權限或禁用賬戶
:::

::: tip 額度管理建議
- 額度調整時填寫備註記錄原因
- 大額調整建議通過訂閱系統而非手動調整
- 定期檢查異常額度變化
:::

::: info 用戶數據安全
- 用戶刪除操作不可逆
- 刪除前確保已備份必要數據
- 敏感資訊變更應有審計記錄
:::
