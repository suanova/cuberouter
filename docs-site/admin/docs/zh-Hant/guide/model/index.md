# 模型管理

模型管理用於管理平臺所有模型的元數據和定價，配置「模型廣場」的展示效果，包括模型資訊、展示狀態、分組權限等。使用管理員賬號登錄後，左側導航點擊「模型」，或直接訪問 `/console/models`。

::: warning 重要說明
本頁面配置**僅影響模型廣場的展示效果**，不會影響模型的實際調用與路由。

若需配置真實的模型調用行為（如 API 接入、負載均衡、故障轉移等），請前往 [渠道管理](../channel/index) 進行設置。
:::

## 快速導航

| 操作 | 說明 |
|------|------|
| [添加 / 編輯模型](#添加-編輯模型) | 配置模型元數據和定價 |
| [同步上游模型](#同步上游模型) | 從服務商同步最新模型列表 |
| [展示權限](#展示權限設置) | 控制模型廣場的可見性 |

## 功能概覽

![模型列表頁](/imgs/model-list.png)

模型列表展示平臺所有已配置的模型，包含模型名稱、類型、輸入/輸出定價、所屬廠商等資訊。

模型管理頁面提供以下功能：

| 功能 | 說明 |
|------|------|
| **模型列表** | 查看所有已配置的模型 |
| **添加模型** | 創建新的模型展示配置 |
| **編輯模型** | 修改模型展示資訊 |
| **啟用/禁用** | 控制模型在模型廣場的可見性 |
| **批量操作** | 批量修改模型的展示配置 |

## 展示配置與實際調用的區別

| 配置項 | 模型管理（展示） | 渠道管理（調用） |
|--------|------------------|------------------|
| 模型可用性 | 控制模型廣場是否顯示 | 控制實際能否調用 |
| 用戶權限 | 控制誰能看到模型 | 控制誰能調用模型 |
| 模型定價 | 展示給用戶的價格資訊 | 實際計費扣款依據 |
| 渠道綁定 | 只讀展示 | 實際配置 |

::: tip 配置優先級
實際調用以**渠道管理**配置為準。模型廣場的展示配置僅影響用戶界面。
:::

## 模型配置

### 基本資訊

| 字段 | 必填 | 說明 |
|------|:----:|------|
| **模型 ID** | ✓ | 模型的唯一標識符，如 `gpt-4-turbo` |
| **模型名稱** | ✓ | 模型在模型廣場的顯示名稱 |
| **供應商** | ✓ | 模型所屬的供應商分類 |
| **模型圖標** | | 模型在界面中顯示的圖標 |

::: info 模型 ID 說明
模型 ID 需要與渠道管理中配置的模型名稱一致，否則用戶在模型廣場選擇後無法正常調用。
:::

### 只讀展示資訊

以下資訊從**渠道管理**自動讀取，在模型管理頁面僅作展示，不可編輯：

| 字段 | 來源 | 說明 |
|------|------|------|
| **已綁定渠道** | 渠道管理 | 顯示哪些渠道配置了該模型 |
| **可用分組** | 渠道管理 | 顯示渠道中配置的用戶組權限 |
| **計費類型** | 渠道管理 | 顯示模型的計費方式 |

::: warning 如何修改這些資訊？
這些資訊由渠道管理決定，如需修改：
1. 前往 [渠道管理](../channel/index)
2. 找到對應的渠道
3. 修改渠道中的模型列表或用戶組配置
:::

### 展示權限設置

| 字段 | 說明 |
|------|------|
| **啟用分組** | 控制哪些用戶組可以在模型廣場看到該模型 |
| **標籤** | 模型的分類標籤，便於用戶篩選 |

**啟用分組選項**：

| 分組 | 說明 |
|------|------|
| **default** | 所有用戶可見 |
| **vip** | 僅 VIP 用戶可見 |
| **自定義組** | 指定用戶組可見 |

::: tip 展示權限 vs 調用權限
- **展示權限**：控制模型廣場是否顯示該模型
- **調用權限**：由渠道管理中的用戶組設置決定

兩者建議保持一致，避免用戶看到模型但無法調用。
:::

### 定價展示配置

| 字段 | 說明 |
|------|------|
| **計費類型** | 展示給用戶的計費方式說明 |
| **輸入價格** | 輸入 token 的價格展示比例 |
| **輸出價格** | 輸出 token 的價格展示比例 |
| **最大上下文** | 模型的最大上下文長度展示 |

::: warning 定價說明
此處配置的價格資訊僅用於**模型廣場展示**，幫助用戶瞭解不同模型的價格差異。

實際扣費依據渠道管理中的配置或系統全局定價設置。
:::

### 端點配置

端點配置定義模型支援的功能類型，用於前端功能展示：

```json
{
  "chat": "/v1/chat/completions",
  "embeddings": "/v1/embeddings",
  "completions": "/v1/completions"
}
```

## 計費類型說明

模型支援兩種計費方式：

| 類型 | 說明 | 展示效果 |
|------|------|----------|
| **按次計費** | 每次請求固定消耗額度 | 適合聊天場景 |
| **按量計費** | 根據 token 數量消耗額度 | 適合長文本處理 |

### 價格比例

價格比例用於展示不同模型的相對成本：

| 模型 | 輸入價格 | 輸出價格 | 說明 |
|------|:--------:|:--------:|------|
| GPT-3.5 | 1 | 1 | 基準模型 |
| GPT-4 | 30 | 60 | 輸入為基準 30 倍 |
| Claude 3 | 15 | 75 | 輸入為基準 15 倍 |

## 模型廣場展示效果

### 啟用/禁用模型

| 狀態 | 模型廣場效果 |
|------|--------------|
| 🟢 **已啟用** | 模型在模型廣場可見 |
| 🔴 **已禁用** | 模型在模型廣場不顯示 |

### 標籤分類

標籤用於在模型廣場中分類展示模型：

| 標籤類型 | 示例 |
|----------|------|
| **按能力** | `對話`、`代碼`、`繪圖`、`嵌入` |
| **按特點** | `長上下文`、`多模態`、`高速` |
| **按用途** | `通用`、`專業`、`企業` |

### 批量啟用

模型管理支援批量操作：

1. 選中多個模型
2. 選擇批量操作類型
3. 設置目標用戶組
4. 確認操作

## 添加 / 編輯模型

1. 點擊「添加模型」按鈕，或點擊已有模型右側的「編輯」按鈕

![添加/編輯模型彈窗](/imgs/model-edit.png)

2. 填寫模型資訊：
   - 模型 ID（與渠道中配置一致）
   - 模型名稱與供應商
   - 輸入價格、輸出價格
3. 配置展示權限（啟用分組、分類標籤）
4. 點擊「保存」完成配置

### 批量修改展示分組

1. 選中需要修改的模型
2. 點擊 **批量修改分組**
3. 選擇目標分組
4. 確認修改

## 同步上游模型

同步功能可從各服務商獲取最新模型列表，預覽變更後再決定是否應用。

1. 在模型管理頁點擊「同步上游」按鈕
2. 系統請求上游服務商的模型列表，彈出預覽彈窗

![同步上游模型預覽彈窗](/imgs/model-sync-preview.png)

3. 預覽彈窗中分別列出「新增」「變更」「刪除」的模型
4. 確認無誤後點擊「應用」，模型列表更新完成

![同步完成後的模型列表](/imgs/model-synced.png)

::: tip 同步建議
建議在渠道配置完成後，使用模型同步功能快速創建模型廣場的展示配置。
:::

| 想要實現的效果 | 配置位置 |

| 控制模型廣場是否顯示某模型 | 模型管理 → 啟用/禁用 |

## 注意事項

::: warning 模型 ID 一致性
模型管理中的模型 ID 必須與渠道管理中的模型名稱一致，否則：
- 用戶在模型廣場選擇模型後可能無法調用
- 渠道綁定的展示資訊無法正確顯示
:::

::: tip 展示與調用配置建議
1. 先在渠道管理配置模型調用
2. 再在模型管理配置展示效果
3. 確保兩邊配置的用戶組一致
:::

::: info 只讀字段
已綁定渠道、可用分組、計費類型等字段從渠道管理讀取，僅作展示。如需修改請前往渠道管理。
:::
