# 分組管理

分組用於隔離不同用戶的渠道訪問權限和計費倍率，是權限管理的核心機制。不同分組的用戶只能使用分配給該分組的渠道。使用管理員賬號登錄後，在系統設置或管理面板中找到「分組」入口。

分組列表展示平臺所有已配置的分組名稱。用戶和令牌均可指定所屬分組，渠道也可限定只對特定分組開放。

## 分組的使用方式

- **用戶分組**：在用戶管理頁編輯用戶時，可為用戶指定所屬分組
- **令牌分組**：創建令牌時可指定該令牌使用的渠道分組
- **渠道分組**：添加渠道時可在「分組」字段填寫允許訪問該渠道的分組名稱

::: info 令牌自動分組
令牌分組設為 `auto` 時，系統按優先級順序自動選擇一個可用分組，適合需要跨分組容災的場景。
:::

## 預置用戶組

| 用戶組 | 說明 | 典型用途 |
|--------|------|----------|
| **default** | 預設用戶組 | 所有新註冊用戶的初始組，基礎權限 |
| **vip** | VIP 用戶組 | 付費用戶或特殊用戶，高級權限 |
| **自定義組** | 管理員創建 | 按業務需求細分權限 |

## 分組與渠道權限

用戶組決定了用戶可以訪問哪些渠道：

```text
用戶組 ──關聯──▶ 渠道 ──包含──▶ 模型
```

::: info 權限邏輯
1. 渠道配置中指定允許訪問的用戶組
2. 用戶所屬用戶組與渠道用戶組匹配時
3. 用戶才能通過該渠道調用模型

例如：
- 用戶 A 屬於 `default` 組
- 渠道 X 配置為 `vip` 組可用
- 用戶 A 無法通過渠道 X 調用模型
:::

### 修改用戶組

1. 在用戶列表中找到目標用戶
2. 點擊 **編輯** 按鈕
3. 修改 **用戶組** 字段
4. 保存更改

::: warning 用戶組變更影響
修改用戶組會立即生效，影響：
- 用戶可訪問的渠道列表
- 用戶在模型廣場可見的模型
- 用戶可調用的模型範圍
:::

## 分組倍率

分組倍率允許為不同用戶組設置差異化的計費倍數，實現靈活的定價策略：

```json
{
  "vip": 0.5,
  "premium": 0.8,
  "standard": 1.0,
  "trial": 2.0
}
```

分組倍率與模型倍率疊加計算：

```text
最終消耗 = Token 數量 × 模型倍率 × 分組倍率
```

**分組倍率優先級**：

1. 用戶專屬倍率：為特定用戶設置的個人倍率
2. 分組倍率：用戶所屬分組的倍率
3. 預設倍率：系統預設倍率（通常為 1.0）

具體配置方法見 [系統設置 - 計費與倍率設置](../system/index#計費與倍率設置)。

## 自動分組設置

控制新用戶的預設分組行為：

| 配置項 | 說明 | 預設值 |
|--------|------|--------|
| **預設使用自動分組** | 是否預設使用自動分組 | 關閉 |
| **自動分組列表** | 自動分組的用戶組列表 | `["default"]` |

::: info 自動分組說明
自動分組用於根據特定規則（如邀請碼、註冊來源等）自動將用戶分配到特定用戶組。配置後，符合條件的用戶會自動加入指定用戶組。
:::

## 注意事項

::: warning 權限規劃
- 分組權限的變更會影響所有組內用戶，變更前先評估影響範圍
- 建議為不同業務場景建立獨立分組，避免權限混雜
- 定期審查分組的渠道授權，及時清理過期配置
:::
