# 兌換碼管理

兌換碼管理用於批量生成和管理配額兌換碼，用於活動贈送或用戶充值。通過兌換碼，管理員可以靈活地進行營銷推廣、用戶激勵等活動。

使用管理員賬號登錄後，左側導航點擊「兌換碼」，或直接訪問 `/console/redemption`。

::: warning 合規提示
兌換碼使用應符合授權範圍、平臺規則和所在地法律法規要求。兌換碼僅用於內部測試、授權客戶交付、活動贈送或賬務調整。
:::

## 兌換碼配置

### 基本資訊

![生成兌換碼彈窗](/imgs/redemption-create.png)

| 字段 | 必填 | 說明 |
|------|:----:|------|
| **名稱** | ✓ | 兌換碼的標識名稱，便於識別批次 |
| **額度** | ✓ | 兌換碼包含的額度值 |
| **數量** | ✓ | 生成兌換碼的數量 |
| **過期時間** | | 兌換碼的有效期限 |

### 過期時間設置

| 選項 | 說明 | 適用場景 |
|------|------|----------|
| **永不過期** | 兌換碼永久有效 | 長期活動、備用額度 |
| **指定時間** | 設置具體的過期時間 | 限時活動、促銷優惠 |

::: warning 過期處理
過期後的兌換碼將無法使用，狀態顯示為「已過期」。過期兌換碼可在列表中篩選查看，建議定期清理。
:::

### 批量生成規則

設置數量後，系統會生成相應數量的兌換碼：

- 每個兌換碼擁有**唯一的兌換碼 Key**
- 同一批次生成的兌換碼共享相同的名稱、額度和過期時間
- 兌換碼 Key 為系統自動生成的隨機字符串

**示例**：

| 名稱 | 額度 | 數量 | 生成結果 |
|------|:----:|:----:|----------|
| 新人禮包 | 10,000 | 50 | 生成 50 個 Key，每個 10,000 額度 |
| 活動獎勵 | 5,000 | 100 | 生成 100 個 Key，每個 5,000 額度 |

## 兌換碼狀態

| 狀態 | 圖標 | 說明 | 可操作 |
|------|:----:|------|:------:|
| **未使用** | 🟢 | 兌換碼可用，等待兌換 | 編輯、刪除、複製 |
| **已使用** | 🔵 | 兌換碼已被使用 | 查看、刪除 |
| **已過期** | 🔴 | 兌換碼已過期，無法使用 | 刪除 |

::: tip 狀態自動變更
- 用戶成功兌換後，狀態自動變更為「已使用」，已使用的兌換碼無法恢復
- 到達過期時間後，狀態自動變更為「已過期」，可通過修改過期時間重新激活
:::

## 操作指南

### 創建兌換碼

1. 在兌換碼列表頁點擊「生成兌換碼」按鈕，彈出生成彈窗
2. 填寫兌換碼資訊：
   - **名稱**：便於識別的批次名稱
   - **面值**：每張兌換碼對應的配額數量
   - **數量**：本次生成的兌換碼張數
3. 點擊「生成」，系統批量創建兌換碼並顯示在列表中

![生成完成後的兌換碼列表](/imgs/redemption-created.png)

::: tip 命名建議
使用有意義的名稱便於後期管理：
- 按活動命名：`雙十一活動`、`新用戶福利`
- 按渠道命名：`官網註冊`、`微信推廣`
- 按等級命名：`體驗額度`、`VIP福利`
:::

### 編輯兌換碼

1. 在兌換碼列表中找到目標兌換碼
2. 點擊 **編輯** 按鈕
3. 修改需要更新的配置：
   - 名稱
   - 額度
   - 過期時間
4. 點擊 **保存** 確認修改

::: warning 編輯限制
- **已使用**的兌換碼無法編輯
- **已過期**的兌換碼可以修改過期時間重新激活
:::

### 刪除兌換碼

1. 在兌換碼列表中找到目標兌換碼
2. 點擊 **刪除** 按鈕
3. 確認刪除操作

::: danger 刪除警告
刪除操作**不可恢復**，請謹慎操作。建議：
- 已使用的兌換碼可保留一段時間作為記錄
- 過期的兌換碼可定期批量清理
:::

### 複製 / 導出兌換碼

- 點擊 **複製** 按鈕，兌換碼 Key 將複製到剪貼板
- 點擊「導出」按鈕，將兌換碼導出為文件，方便批量分發

## 用戶兌換流程

### 用戶端操作

用戶可以通過以下步驟兌換額度：

1. 登錄賬戶
2. 進入 **個人中心** → **兌換中心**
3. 輸入兌換碼 Key
4. 點擊 **兌換** 按鈕
5. 系統驗證併發放額度

### 兌換規則

| 規則 | 說明 |
|------|------|
| 單次使用 | 每個兌換碼只能使用一次 |
| 不可重複 | 已使用的兌換碼無法再次使用 |
| 有效期限制 | 過期的兌換碼無法使用 |
| 即時到賬 | 兌換成功後額度立即到賬 |

### 兌換失敗情況

| 錯誤提示 | 原因 | 解決方案 |
|----------|------|----------|
| 兌換碼不存在 | 輸入的 Key 有誤 | 檢查是否複製正確 |
| 兌換碼已使用 | 該碼已被兌換 | 使用其他兌換碼 |
| 兌換碼已過期 | 已超過有效期 | 聯繫管理員獲取新碼 |

## 使用場景

### 營銷推廣

| 場景 | 配置建議 |
|------|----------|
| 新用戶註冊 | 名稱：`新用戶福利`，額度適中，數量大 |
| 促銷活動 | 設置過期時間，配合活動週期 |
| 合作推廣 | 按渠道命名，便於追蹤效果 |

### 用戶激勵

| 場景 | 配置建議 |
|------|----------|
| 邀請獎勵 | 名稱：`邀請獎勵`，額度較高 |
| 活動獎品 | 限量生成，設置過期時間 |
| 補償發放 | 單獨生成，備註原因 |

### 測試用途

| 場景 | 配置建議 |
|------|----------|
| 功能測試 | 名稱：`測試`，額度小 |
| 開發調試 | 不設過期時間，隨時生成新碼用於測試（每個碼仍為單次使用） |

## 注意事項

::: warning 安全保管
兌換碼 Key 具有價值，請妥善保管：
- 不要在公開場合分享兌換碼
- 發放時使用私密渠道
- 定期檢查未使用兌換碼的狀態
:::

::: tip 批量管理建議
- 使用有意義的命名便於識別
- 定期清理已使用和過期的兌換碼
- 大量發放時建議分批次生成
:::

::: info 額度計算
兌換碼額度與系統額度單位一致。用戶兌換後，額度會**累加**到用戶當前餘額，而不是覆蓋。
:::
