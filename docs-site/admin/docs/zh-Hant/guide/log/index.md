# 日誌與統計

日誌與統計用於查看全平臺 API 調用記錄和消耗統計，支援按用戶、模型、渠道等多維度分析。使用管理員賬號登錄後，左側導航點擊「日誌」，或直接訪問 `/console/log`。

## 快速導航

| 操作 | 說明 |
|------|------|
| [日誌列表](#功能概覽) | 查看全平臺調用記錄 |
| [搜索與過濾](#搜索與過濾) | 多維度篩選日誌 |
| [日誌統計面板](#日誌統計面板) | 全平臺調用量彙總 |
| [全平臺消耗趨勢](#全平臺消耗趨勢) | 消耗趨勢與用戶分佈 |

## 功能概覽

![全平臺日誌列表](/imgs/admin-log.png)

管理員視角的日誌列表比普通用戶多出「用戶名」和「渠道名」兩列，可查看所有用戶的調用記錄。

日誌列表展示每次 API 調用的詳細資訊：

| 字段 | 說明 |
|------|------|
| **用戶** | 調用者用戶名（管理員可見全部用戶） |
| **渠道** | 實際處理請求的渠道（管理員可見） |
| **令牌** | 調用所使用的 API 令牌 |
| **模型** | 請求的模型名稱 |
| **分組** | 令牌所屬的渠道分組 |
| **提示詞/補全 token** | 輸入與輸出 token 數量 |
| **消耗** | 本次調用消耗的配額 |
| **響應時間** | 請求耗時 |
| **狀態** | 請求結果（成功 / 失敗及原因） |

## 搜索與過濾

1. 在日誌頁頂部點擊「篩選」按鈕，展開過濾條件區域
2. 可設置以下過濾條件：
   - **時間範圍**：選擇開始和結束日期
   - **用戶名**：輸入用戶名關鍵詞
   - **模型**：輸入模型名稱關鍵詞
   - **渠道**：選擇特定渠道
   - **令牌名**：輸入令牌名稱
3. 點擊「查詢」，列表刷新顯示過濾結果

![日誌篩選條件展開狀態](/imgs/admin-log-filter.png)

## 日誌統計面板

在日誌頁頂部查看統計彙總區域，展示全平臺的調用量彙總數據。

![日誌統計面板（總調用次數、總消耗配額等）](/imgs/admin-log-stat.png)

統計面板包含以下指標：

| 指標 | 說明 |
|------|------|
| **總調用次數** | 時間範圍內的 API 調用總量 |
| **總消耗配額** | 時間範圍內的配額消耗總量 |
| **總 Token 數** | 輸入與輸出 Token 總和 |
| **成功率** | 成功請求佔比 |

## 全平臺消耗趨勢

1. 左側導航點擊「數據看板」，或直接訪問 `/console`（管理員視角）

![全平臺消耗趨勢圖](/imgs/admin-dashboard.png)

2. 管理員數據看板展示全平臺的消耗趨勢折線圖，以及各用戶的消耗佔比分佈
3. 將鼠標懸停在圖表上可查看具體日期的詳細數據

## 使用日誌

普通用戶在使用日誌頁可以查看自己的調用記錄，管理員可以看見**所有用戶**的日誌：

![使用日誌](/imgs/usage-log.png)

使用日誌展示調用 API 時所使用的令牌分組、模型和花費。

## 注意事項

::: tip 日誌運維建議
- 日誌數據量較大時建議定期歸檔或清理
- 結合 [系統設置 - 其他設置](../system/index#其他設置) 中的日誌保留天數配置，控制存儲佔用
- 排查問題時優先使用篩選功能定位目標請求
:::

::: warning 日誌可見性
- 普通用戶只能查看自己的調用記錄
- 管理員可查看全平臺日誌（含用戶名、渠道名列）
- 日誌中的敏感資訊請按合規要求管理
:::
