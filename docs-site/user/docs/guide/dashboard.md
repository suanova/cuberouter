# 概览与数据看板

> 登录后默认进入「概览」页，这里整合了账户用量、API 信息、公告等核心信息。

## 概览页

左侧导航点击「概览」，或直接访问 `/dashboard/overview`。

![概览页](/imgs/dashboard.jpeg)

概览页展示以下内容：

- **开始使用**：三步引导——创建 API 密钥、添加额度、发送请求，附 curl 调用示例
- **用量概览**：近 24 小时消耗、历史使用情况、请求计数、剩余额度
- **性能健康**：服务性能指标
- **API 信息**：API 地址、文档入口，可直接复制
- **公告**：最新系统公告
- **常见问答**：常见问题展开查看

## 数据看板

左侧导航点击「数据看板」，或直接访问 `/dashboard/models`，以图表形式查看账户的使用情况。

![数据看板](/imgs/data-dashboard.jpeg)

数据看板提供以下统计维度：

### 使用统计

- **请求次数**：API 请求总量
- **趋势图表**：折线图展示请求次数的时间变化趋势

### 资源消耗

- **消耗额度**：已消耗的额度金额
- **消耗 Tokens**：Token 消耗总量
- **趋势可视化**：折线图展示额度 / Tokens 消耗趋势

### 性能指标

- **平均 RPM**：每分钟请求数
- **平均 TPM**：每分钟 Token 数

### 模型数据分析

多维度分析模型使用情况：

- **消耗分布**：不同时间段的消耗分布（柱状图）
- **消耗趋势**：模型消耗随时间的变化趋势（折线图）
- **调用次数分布**：各模型在总调用次数中的占比（环形图）
- **调用次数排行**：模型的调用次数排名（柱状图）

将鼠标悬停在图表上可查看具体日期的详细数据。

## 核心数据展示

| 模块 | 数据项 | 说明 |
| --- | --- | --- |
| 用量概览 | 近 24 小时消耗 | 最近一天的消耗金额 |
| 用量概览 | 历史使用情况 | 累计消耗金额 |
| 用量概览 | 请求计数 | API 请求总量 |
| 用量概览 | 剩余额度 | 账户可用余额 |
| 使用统计 | 请求次数 | API 请求总量 |
| 资源消耗 | 消耗额度 | 已消耗的额度金额 |
| 资源消耗 | 消耗 Tokens | Token 消耗总量 |
| 性能指标 | 平均 RPM | 每分钟请求数 |
| 性能指标 | 平均 TPM | 每分钟 Token 数 |

## 核心价值

1. **财务透明**：实时查看余额、消耗历史
2. **使用洞察**：量化 API 调用、Token 消耗、性能指标
3. **趋势分析**：通过多维度图表识别使用模式和异常
4. **模型分析**：了解各模型的调用频率和消耗占比
