# 游乐场

> 游乐场是 CubeRouter 提供的 AI 模型在线测试和对话工具，无需编写代码即可直接与模型对话，适合快速验证密钥和模型效果。

左侧导航点击「游乐场」，或直接访问 `/playground`。

![游乐场页面](/imgs/playground.jpeg)

## 功能概述

- 🎛️ **模型配置**：灵活配置模型参数，满足不同场景需求
- 💬 **实时对话**：与 AI 模型进行实时对话测试
- 📊 **调试模式**：查看完整的请求和响应细节
- 💾 **配置管理**：保存、导入、导出模型配置

## 使用游乐场

1. 在页面顶部选择要测试的模型
2. 在底部输入框输入消息内容，点击发送
3. 对话区域显示模型的回复结果

![游乐场对话示例](/imgs/playground.jpeg)

回复下方显示响应时间，并提供以下操作按钮：

- **复制**：一键复制消息内容
- **显示源码**：查看原始 Markdown 内容
- **重新生成**：重新生成当前回复
- **编辑**：编辑已发送的消息
- **删除**：删除当前消息

页面还提供「入门提示词」快捷按钮（分析数据、总结文本、代码、获取建议），方便快速开始测试。

## 参数设置

点击输入框旁的「参数」按钮，可打开参数设置弹窗，配置模型参数。只有启用的参数会随请求发送。

![参数设置](/imgs/playground-params.jpeg)

### Temperature（温度）

- 控制输出的随机性和创造性
- 范围：0.0 - 2.0，默认值：0.7
- 低温度（0.0 - 0.3）：输出更确定、更一致，适合代码生成
- 高温度（0.8 - 2.0）：输出更随机、更有创意，适合创意写作

### Top P（核采样）

- 控制词汇选择的多样性
- 范围：0.0 - 1.0，默认值：1.0
- 通常不需要调整，建议优先调整 Temperature

### Frequency Penalty（频率惩罚）

- 减少重复词汇的出现频率
- 范围：-2.0 - 2.0，默认值：0
- 正值：惩罚已出现的词汇，避免重复

### Presence Penalty（存在惩罚）

- 鼓励讨论新话题
- 范围：-2.0 - 2.0，默认值：0
- 正值：鼓励讨论新话题

### Max Tokens（最大输出长度）

- 控制输出的最大 Token 数量
- 默认值：4096
- 注意模型的最大 Token 限制

### Seed（随机种子）

- 用于复现相同的输出结果
- 留空则每次输出可能不同

## 参数配置建议

**代码生成**：

- Temperature：0.2
- Top P：0.5
- Frequency Penalty：0.0
- Presence Penalty：0.0

**创意写作**：

- Temperature：0.9
- Top P：0.9
- Frequency Penalty：0.3
- Presence Penalty：0.6

**问答对话**：

- Temperature：0.7
- Top P：1.0
- Frequency Penalty：0.0
- Presence Penalty：0.0

## 使用场景

### 快速测试模型

1. 打开游乐场
2. 选择要测试的模型
3. 输入问题
4. 查看模型回复
5. 调整参数重新测试

### 调整生成效果

1. 输入问题，查看初始回复
2. 不满意时调整参数：
   - 提高 Temperature 增加创意
   - 降低 Temperature 提高精确性
   - 调整 Top P 控制多样性
3. 重新生成回复

## 核心价值

1. **快速测试**：无需编写代码即可测试模型效果
2. **参数调优**：直观调整参数找到最佳配置
3. **实时反馈**：即时看到参数变化的影响
4. **配置管理**：保存、分享、导入配置
