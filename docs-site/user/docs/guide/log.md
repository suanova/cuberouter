# 使用日志

> 查看每次 API 调用的详细信息，支持按时间、模型、令牌等条件过滤。左侧导航点击「使用日志」，或直接访问 `/usage-logs/common`。普通用户只能看到自己的调用记录。

![使用日志](/imgs/log.jpeg)

## 查看使用记录

日志列表每行展示一次调用记录，包含以下信息：

| 列 | 说明 |
| --- | --- |
| **时间** | 调用时间 |
| **类型** | 流式 / 非流式 |
| **模型** | 调用的模型名称 |
| **Token** | 输入 / 输出 Token 数 |
| **消耗** | 本次调用消耗的配额 |
| **首字** | 首字返回耗时 |
| **总耗时** | 请求总耗时 |
| **IP** | 发起请求的客户端 IP |
| **渠道** | 实际处理请求的上游渠道 |
| **令牌名** | 使用的 API 密钥名称 |
| **操作** | 查看该次调用的详细信息 |

点击「操作」列的「详情」可查看该次调用的完整请求与响应内容。

## 搜索与过滤

### 设置过滤条件

1. 在日志页顶部的过滤工具栏中设置过滤条件：
   - **时间范围**：选择开始和结束日期
   - **类型**：按调用类型（流式 / 非流式）筛选
   - **模型名称**：输入模型名称关键词
   - **分组**：选择 API 密钥的分组
   - **令牌名 / 用户名**：按密钥名称或用户名筛选
   - **渠道 ID / 请求 ID / 上游请求 ID**：精确定位某次调用
2. 设置完成后点击「查询」，列表刷新显示过滤结果；点击「重置」可清除条件

### 查看过滤结果

设置完成后列表自动刷新显示过滤结果。

## 用量汇总

列表顶部展示汇总统计：

- **用量**：筛选范围内的总消耗金额
- **RPM**：每分钟请求数
- **TPM**：每分钟 Token 数

## 数据统计

### 访问数据看板

左侧导航点击「数据看板」，或直接访问 `/dashboard/models`，以折线图或柱状图展示每日 API 调用量和配额消耗趋势。将鼠标悬停在图表上可查看具体日期的详细数据。详见[概览与数据看板](dashboard.md)。
