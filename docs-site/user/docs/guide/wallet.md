# 配额与充值

> 配额是平台内部计费单位，消耗量 = 实际 Token 数 × 模型倍率。左侧导航点击「钱包」，或直接访问 `/wallet`。

::: warning 合规提醒
充值、兑换码和邀请链接适用于合法授权场景。使用时应符合授权范围、上游服务条款、平台规则和所在地法律法规要求。
:::

![钱包页面](/imgs/wallet.jpeg)

支付方式由管理员在系统设置 → 支付设置中配置。

## 账户统计

页面顶部实时展示账户的核心数据指标：

- **当前余额**：账户可用余额
- **总用量**：累计消耗金额
- **API 请求**：API 请求总量

## 充值方式

支持在线支付充值和兑换码两种方式增加账户配额。

| 充值方式 | 说明 |
| --- | --- |
| 兑换码 | 输入管理员生成的兑换码，直接增加配额 |
| EPay | 国内聚合支付（支付宝、微信等） |
| Stripe | 国际信用卡支付 |
| Creem / Waffo | 国际支付平台 |

## 在线支付充值

### 选择充值金额

在「添加资金」区域选择预设金额，或手动输入自定义金额。

### 完成支付

1. 选择支付方式（EPay / Stripe / Creem / Waffo）
2. 点击「充值」按钮，页面跳转至对应支付平台
3. 在支付平台完成付款后，自动跳回平台，账户余额更新

## 兑换码充值

### 输入兑换码

1. 在「兑换码」输入框中粘贴或输入管理员提供的兑换码
2. 点击「兑换额度」按钮，系统验证兑换码有效性
3. 兑换成功后页面提示获得的配额数量，账户余额同步更新

## 订阅套餐

在钱包页面的「订阅套餐」区域可以查看和订阅按周期购买的套餐。详见[订阅计划](subscription.md)。

## 邀请返利

每个账号都有唯一的邀请链接，当其他人通过你的邀请链接注册成功时，你即可获得邀请奖励。

### 获取邀请链接

在钱包页面的「推荐计划」区域，复制你的专属邀请链接。

### 邀请奖励机制

1. **注册即返利**：被邀请人使用你的邀请链接注册成功后，你（邀请人）会立即获得系统配置的一笔「邀请奖励配额」（一次性到账）。
2. **转入余额**：点击「转入余额」按钮，即可将累计的返利配额转入你的账户主余额中进行使用。

## 核心数据展示

| 模块 | 数据项 | 说明 |

| 账户统计 | 当前余额 | 账户可用余额 |
| 账户统计 | 总用量 | 累计消耗金额 |
| 账户统计 | API 请求 | API 请求总量 |

## 使用场景

### 场景 1：使用兑换码

1. 进入钱包页面
2. 查看当前余额和总用量
3. 使用兑换码兑换额度（如有）

### 场景 2：邀请好友获利

1. 复制邀请链接
2. 分享给好友或社交平台
3. 好友注册后，获得奖励
4. 定期查看收益统计
5. 将奖励划转到账户余额使用

## 核心价值

1. **余额透明**：实时查看账户余额和消耗情况
2. **记录可查**：完整的消费记录，便于对账
3. **奖励激励**：邀请好友获得额外收益
4. **收益管理**：清晰的收益统计和划转功能
