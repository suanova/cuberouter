# 定价说明

> 了解 CubeRouter 的计费规则：按量计费与按次计费、配额如何消耗、如何核对账单。

模型价格一览及筛选浏览见[模型广场](models-market.md)。

## 计费单位：配额

平台以「配额」作为内部计费单位，所有余额、消费、账单均以配额显示。

- 充值（在线支付 / 兑换码 / 订阅套餐 / 邀请返利）会增加账户配额
- 每次 API 调用按计费规则折算出消耗配额，从账户余额中扣除

## 两种计费类型

| 类型 | 计费方式 | 适用模型 |
| --- | --- | --- |
| **按量计费** | 按实际使用的 Token 数量计费 | 对话、补全、嵌入等文本类模型 |
| **按次计费** | 每次调用收取固定价格，不随 Token 数量变化 | 图像生成、视频生成、TTS 等任务类模型 |

### 按量计费

- **输入价格**：输入 Token 的单价（模型广场中可切换 `/1M` 或 `/1K` 显示单位）
- **输出价格**：输出 Token 的单价
- 实际消耗 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价

部分模型还支持更细粒度的定价，在价格中体现为单独单价：

- **缓存命中（读取）**：命中提示缓存的 Token 单价通常远低于普通输入
- **缓存创建**：首次写入缓存的 Token 单价通常略高于普通输入
- **图片 / 音频**：多模态输入输出的 Token 按各自的单价计费

::: tip 价格显示
模型广场的价格以美元单价展示（如 `$3 / 1M`），最终扣减的配额数量由平台按统一汇率折算。以使用日志中显示的实际扣减为准。
:::

### 按次计费

按次计费模型每次调用扣取固定配额，与请求内容长短无关。例如：

- 图像生成：按「每次生成」计价，生成多张时按张数累加
- 视频生成：按固定时长或固定规格计价
- 语音合成 / 识别：按次或按时长计价

具体规格与价格以模型广场中该模型的说明为准。

## 分组倍率

平台支持按「分组」对用户应用不同的计费倍率：

- 不同分组可能享有不同的折扣或倍率
- 创建 API 密钥时选择的分组决定该密钥适用的计费倍率
- 实际消耗以使用日志中的扣减金额为准

## 如何核对账单

| 位置 | 查看内容 |
| --- | --- |
| 「使用日志」 | 每次调用的输入 / 输出 Token 数与扣减配额 |
| 「任务日志」 | 任务类调用（图像、视频等）的状态与消耗 |
| 「钱包」 | 账户当前余额与充值记录 |
| 「数据看板」 | 按模型 / 用户维度的用量统计 |

如发现扣减金额与预期不符，可在使用日志中查看该次调用的 Token 明细，并联系管理员确认模型定价与分组倍率配置。

## 常见问题

### Q1: 为什么日志里的 Token 数比模型广场的价格页面显示的多？

按量计费的模型可能包含缓存 Token、多模态 Token 等，它们按各自单价单独计费。使用日志中的「输入 / 输出」是汇总值，明细可在日志详情中查看。

### Q2: 免费调用也会扣配额吗？

只要调用了非免费模型，就会按计费规则扣取配额。管理员可配置部分模型或分组为免费，此时扣减为 0。

### Q3: 余额不足会发生什么？

余额不足时，API 调用会被拒绝（返回 401 / 余额不足错误），已开始的流式响应可能被中断。请及时充值，或在「个人设置 → 通知设置」中开启配额告警。
