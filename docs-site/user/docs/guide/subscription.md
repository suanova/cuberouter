# 订阅计划

> 订阅是按周期购买的套餐，购买后在有效期内享受套餐内的配额或特权，适合有稳定用量需求的用户。

订阅套餐提供按周期计费的配额包，可选择日、周、月等不同周期的套餐。

## 查看订阅套餐

在「钱包」页面的「订阅套餐」区域，可以查看所有可购买的套餐，包含套餐名称、价格、有效期、包含配额等信息。

![订阅套餐](/imgs/wallet.jpeg)

- **我的订阅**：展示当前账号生效中的订阅及其有效期
- **优先钱包**：可选择将某个订阅的额度优先使用，避免与账户余额混用
- **优先订阅偏好**：已保存的偏好会在每次调用时优先生效

## 订阅流程

### 浏览套餐信息

在「订阅套餐」区域浏览可用套餐，查看各套餐的价格、有效期和包含配额。

### 立即订阅

1. 选择要订阅的套餐
2. 点击「立即订阅」按钮
3. 按提示完成支付
4. 订阅成功后，套餐配额立即生效，可在「我的订阅」中查看

## 查看当前订阅状态

购买订阅后，在「我的订阅」区域可查看当前套餐的详细信息：

- 套餐名称和有效期截止日期
- 套餐内剩余配额

## 自动续费设置

可在此设置到期后是否自动续费。

::: tip 提示
订阅配额与账户余额是独立计算的。当配置了「优先钱包 / 优先订阅」时，调用会优先消耗订阅内的配额，用尽后再回落到账户余额。
:::
