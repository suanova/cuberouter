# 个人资料

> 管理账号基本信息、安全设置和第三方账号绑定。登录后点击右上角头像，在下拉菜单中选择「个人资料」，或直接访问 `/profile`。

![个人设置](/imgs/profile.jpeg)

## 基本信息

页面顶部展示账户概览：用户名、用户 ID、当前分组、当前余额、总用量、API 请求数。

### 语言偏好

切换界面显示语言，支持简体中文、繁體中文、English、Français、Русский、日本語、Tiếng Việt 等，切换后自动保存。

## 第三方账号绑定

将 GitHub、Discord 等第三方账号与当前账号绑定后，可直接用第三方账号登录，无需输入密码。

支持的绑定平台包括：Email、Phone、GitHub、Discord、LinuxDO、OIDC、Telegram、WeChat 及自定义 OAuth。

### 绑定第三方账号

1. 在「账户绑定」区域找到要绑定的平台
2. 点击对应平台的「绑定」按钮
3. 页面跳转至该平台的授权页面，登录并点击「授权」
4. 授权完成后自动跳回，绑定状态变为「已绑定」
5. 已绑定的平台可点击「解绑」解除绑定

## 安全设置

### 更改密码

点击「更改密码」，依次填写当前密码、新密码、确认新密码，点击「确认修改」完成。

### 两步验证（2FA）

开启两步验证后，每次登录时除密码外还需输入验证器 App 中的动态码，有效防止账号被盗。

#### 开启两步验证

1. 在手机上安装验证器 App（推荐 Google Authenticator 或 Microsoft Authenticator）
2. 在「安全」区域找到「两步验证」，点击「启用」
3. 用验证器 App 扫描页面上显示的二维码，App 中会出现一个 6 位动态码
4. 将 App 中显示的 6 位动态码填入验证框，点击「确认启用」
5. 系统显示一组备用码，请立即截图或抄写保存，用于无法使用验证器时的紧急登录

::: warning 重要提醒
备用码只显示一次，关闭弹窗后无法再次查看。丢失备用码且无法使用验证器时，需联系管理员重置。
:::

### Passkey 无密码登录

Passkey 支持使用设备指纹、面容识别或硬件安全密钥登录，无需输入密码。

#### 注册 Passkey

1. 在「安全」区域找到「Passkey 登录」
2. 点击「启用 Passkey」
3. 浏览器弹出系统验证提示，按提示完成指纹、面容或安全密钥验证
4. 验证通过后 Passkey 注册完成，下次登录时可直接使用

### 登录会话

展示当前账号的活跃登录会话，包括设备类型、IP 地址等信息。可以：

- **登出**：退出指定会话
- **退出其他会话**：一次性退出除当前会话外的所有会话

## 通知设置

配置接收系统通知的方式，支持多种推送渠道。

- **通知邮箱**：设置接收通知的邮箱，留空则使用账户邮箱
- **通知方式**：可选 Webhook、Gotify、Bark Push、Telegram 等
- **配额告警阈值**：当余额低于设定值时发送提醒
- **上游模型更新通知**：接收上游模型更新通知
- **消息优先级**：设置推送消息的优先级

以 Webhook 为例：

1. 选择「Webhook」通知方式
2. 填写 Webhook URL（接收通知的接口地址）
3. 可设置 Webhook Secret 用于签名校验
4. 点击「保存设置」完成配置

Webhook 推送的数据格式为 JSON，包含事件类型、时间戳和详细信息。

## 价格设置

控制是否允许调用未设置价格的模型。

### 配置价格策略

- **接受未定价模型**：开启后可调用所有模型，未定价模型按默认倍率计费；关闭则只能调用已设置价格的模型（推荐）

::: warning 重要提醒
允许未定价模型可能导致意外的高额消耗，建议保持默认的「拒绝未定价模型」设置。
:::

## IP 记录设置

控制是否在日志中记录 API 调用的来源 IP 地址。

### 开启 IP 记录

- **记录 IP 地址**：开启后，在使用日志页面可以看到每次调用的来源 IP

IP 记录有助于：

- 监控异常访问
- 排查安全问题
- 分析流量来源

## 删除账户

在「安全」区域底部可发起删除账户操作。删除前请确保已处理完毕余额和密钥，删除后数据不可恢复。
