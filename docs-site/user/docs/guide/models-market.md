# 模型广场

> 模型广场是 CubeRouter 的模型展示和价格查询中心，帮助快速找到目标模型并了解定价。

点击顶部导航栏的「模型广场」，或直接访问 `/pricing`。

![模型广场](/imgs/models-market.jpeg)

## 功能概述

- 📊 **模型浏览**：查看所有可用的 AI 模型
- 🔍 **智能筛选**：按分组、供应商、标签、计费类型等多维度筛选
- 💰 **价格透明**：清晰展示每个模型的定价信息
- 📋 **便捷复制**：一键复制模型名称用于 API 调用

## 筛选面板

左侧筛选面板提供多维度筛选条件，帮助快速找到目标模型。点击「重置」可清空所有筛选条件，恢复默认视图。

- **分组**：按 API 密钥的分组筛选，查看当前密钥可访问的模型
- **供应商**：按模型供应商筛选（如 OpenAI、Claude、Gemini 等）
- **模型标签**：按标签筛选（如 chat、code、image 等）
- **定价类型**：按量计费 / 按次计费
- **端点类型**：按 API 端点类型筛选（Chat、Responses、Anthropic、Gemini、Rerank、图片、嵌入、视频等）

## 模型展示区

### 搜索栏

在搜索框中输入模型名称关键字（快捷键 `⌘K`），列表自动显示匹配的模型。

### 价格显示

工具栏提供 `/1M` 与 `/1K` 切换，控制价格按每百万或每千 Token 显示。

每个模型展示以下信息：

- **模型名称**：完整的模型标识符（如 `deepseek-v4-flash`）
- **价格信息**（按量计费模型）：输入价格、输出价格（如 `$0.1 / $0.1`）
- **价格信息**（按次计费模型）：每次调用的固定价格
- **计费类型标签**：按量计费 / 按次计费

### 视图切换

- **卡片视图**：以卡片形式展示模型（默认）
- **表格视图**：以表格形式展示模型

## 计费类型说明

**按量计费**：

- 根据实际使用的 Token 数量计费
- 输入 Token 和输出 Token 价格不同
- 价格 = 输入 Token × 输入单价 + 输出 Token × 输出单价

**按次计费**：

- 每次调用固定价格，不受 Token 数量影响
- 价格 = 调用次数 × 单次价格

## 使用场景

### 查找特定模型

1. 打开模型广场
2. 在搜索框输入模型名称关键字
3. 查看匹配的模型列表
4. 点击复制按钮获取模型名称

### 查看当前密钥可用模型

1. 打开模型广场
2. 按「分组」筛选出 API 密钥对应的分组
3. 查看该分组可访问的模型
4. 复制模型名称用于 API 调用

### 比较模型价格

1. 按供应商或标签筛选
2. 切换 `/1M` / `/1K` 价格显示
3. 对比不同模型的输入 / 输出价格
4. 选择性价比最高的模型

## 常见问题

### Q1: 如何快速找到我需要的模型？

使用筛选和搜索功能：先按标签或供应商筛选，再在搜索框输入关键字，快速定位目标模型。

### Q2: 按量计费和按次计费有什么区别？

- **按量计费**：根据 Token 数量计费，价格 = 输入价格 + 输出价格
- **按次计费**：每次调用固定价格，不受 Token 数量影响

### Q3: 为什么有些模型我看不到？

可能的原因：当前密钥分组权限不足、模型已下线或维护中、筛选条件过滤掉了该模型。

### Q4: 如何查看模型的详细价格？

在模型卡片中查看：按量计费显示输入 / 输出价格，按次计费显示单次价格，可切换 `/1M` / `/1K` 显示单位。
