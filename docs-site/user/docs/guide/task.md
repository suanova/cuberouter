# 任务日志

> 管理 Midjourney 绘图、Suno 音乐生成等异步任务的状态与结果。左侧导航点击「任务日志」，或直接访问 `/usage-logs/task`。

![任务日志](/imgs/task.jpeg)

任务日志页提供两个标签页：

- **绘图日志**：查看绘图类任务（Midjourney 等）的记录
- **任务日志**：查看音乐生成等其他异步任务（Suno 等）的记录

## 查看任务列表

任务列表展示所有已提交的异步生成任务，包含以下信息：

- **提交时间**：任务提交的时间
- **任务 ID**：任务的唯一标识
- **耗时**：任务执行耗时
- **状态**：任务的当前状态
- **进度**：任务完成进度
- **详情**：查看任务详细结果

可通过「任务 ID」过滤条件筛选特定任务。

## 任务状态说明

| 状态 | 说明 |
| --- | --- |
| `PENDING` | 任务已提交，等待处理 |
| `IN_PROGRESS` | 任务正在生成中 |
| `SUCCESS` | 任务已完成，可查看结果 |
| `FAILURE` | 任务生成失败，已自动退还配额 |
