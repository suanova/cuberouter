# 界面概覽

> 歡迎使用 CubeRouter！本指南將帶你快速瞭解平臺界面。

## 平臺界面整體介紹

CubeRouter 採用現代化的響應式設計，界面簡潔直觀。登入後的控制台由**左側邊欄**和**主內容區域**組成；公開頁面（首頁、模型廣場等）由**頂部導航欄**和主內容區域組成。

![平臺首頁](/imgs/home.jpeg)

## 頂部導航欄

![控制台界面](/imgs/dashboard.jpeg)

頂部導航欄包含 Logo、導航項和右側功能區域。導航項由站點配置決定，默認通常包括：

- **Logo**：點擊跳轉平臺首頁，展示產品介紹、使用步驟和 API 調用示例
- **模型廣場**：瀏覽可用模型列表和定價資訊
- **排行榜**：查看模型用量排行
- **關於**：瞭解更多關於平臺的資訊

## 頂部右側區域

- **消息通知**：當有未讀系統公告或應用內通知時，圖標上方顯示紅色數字徽章，點擊後可查看系統公告和賬戶通知
- **語言切換**：支援簡體中文、繁體中文、English 等語言，切換後自動保存
- **主題切換**：支援淺色模式、深色模式和跟隨系統的自動模式以及顏色等
- **用戶區域**：
  - 未登入狀態：顯示「登入」按鈕
  - 已登入狀態：顯示用戶頭像（首字母）和用戶名，點擊展開下拉菜單：
    - **個人資料**：修改個人資訊、安全設置等
    - **錢包**：查看餘額和充值
    - **退出**：退出當前賬戶

## 左側邊欄（控制台）

登入進入控制台後，左側邊欄提供以下功能入口：

| 菜單 | 說明 |
| --- | --- |
| 遊樂場 | 在線測試模型對話效果 |
| 概覽 | 賬戶用量概覽、API 資訊、公告和常見問答 |
| 數據看板 | 調用量、Token 消耗、性能指標等多維度統計 |
| API 金鑰 | 創建和管理調用 API 的金鑰 |
| 使用日誌 | 查看每次 API 調用的詳細記錄 |
| 任務日誌 | 查看繪圖、音樂生成等異步任務 |
| 錢包 | 餘額管理、充值、兌換碼和邀請返利 |
| 個人資料 | 個人設置等 |

> 不同角色的用戶看到的菜單不同：管理員和運營用戶還會看到渠道管理、模型管理、用戶管理、系統設置等額外菜單。

## 概覽頁

登入後的默認頁面是「概覽」，展示：

![概覽頁](/imgs/dashboard.jpeg)

- **設置引導**：創建 API 金鑰、添加額度、發送請求的三步引導
- **用量概覽**：近 24 小時消耗、歷史使用情況、請求計數、剩餘額度
- **API 資訊**：API 地址、文檔入口
- **公告**：最新系統公告
- **常見問答**：常見問題展開查看
- **運行時間**：服務性能指標
