# 註冊與登入

> 支援賬號密碼註冊，以及多種第三方 OAuth 一鍵登入。首次使用請先完成註冊。

## 註冊

### 註冊流程

1. 訪問首頁，點擊「獲取 API Key」按鈕，或直接訪問 `/sign-up`

![註冊頁面](/imgs/register.jpeg)

2. 填寫註冊資訊：
   - **用戶名**：登入用戶名，建議使用英文，用戶名一旦註冊不可修改
   - **郵箱**：用於接收驗證碼（必填）
   - **密碼**：登入密碼（8-20 位，建議包含字母和數字）
   - **手機號**（可選）：部分平臺啟用手機驗證時需要填寫
3. 點擊「註冊」完成賬號創建

::: tip 推薦做法
- 開啟[兩步驗證](../guide/personal-setting.md#兩步驗證2fa)，為賬戶添加額外的安全層
- 定期更換密碼，建議每 3-6 個月更換一次
- 謹慎使用公共網路，避免在公共 WiFi 下登入重要賬戶
- 保護賬戶資訊，不向他人透露賬戶密碼、驗證碼
:::

## 登入

### 賬號密碼登入

1. 訪問首頁，點擊右上角「登入」按鈕，或直接訪問 `/sign-in`

![登入頁面](/imgs/login.jpeg)

2. 輸入用戶名和密碼，點擊「登入」完成登入

### 第三方 OAuth 登入

如平臺已配置第三方登入，點擊登入頁下方對應平臺的圖標（GitHub、Discord、LinuxDO、Telegram、OIDC 等），跳轉至第三方授權頁面完成授權後自動登入。

### 忘記密碼

忘記密碼時，點擊登入頁的「忘記密碼」鏈接，輸入註冊郵箱後系統會發送重置鏈接，點擊鏈接設置新密碼，原密碼隨即失效。

## 支援

如果在註冊或登入過程中遇到任何問題，可前往[聯繫支援](../support/contact.md)尋求幫助。
