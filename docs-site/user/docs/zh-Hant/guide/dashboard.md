# 概覽與數據看板

> 登入後默認進入「概覽」頁，這裡整合了賬戶用量、API 資訊、公告等核心資訊。

## 概覽頁

左側導航點擊「概覽」，或直接訪問 `/dashboard/overview`。

![概覽頁](/imgs/dashboard.jpeg)

概覽頁展示以下內容：

- **開始使用**：三步引導——創建 API 金鑰、添加額度、發送請求，附 curl 調用示例
- **用量概覽**：近 24 小時消耗、歷史使用情況、請求計數、剩餘額度
- **性能健康**：服務性能指標
- **API 資訊**：API 地址、文檔入口，可直接複製
- **公告**：最新系統公告
- **常見問答**：常見問題展開查看

## 數據看板

左側導航點擊「數據看板」，或直接訪問 `/dashboard/models`，以圖表形式查看賬戶的使用情況。

![數據看板](/imgs/data-dashboard.jpeg)

數據看板提供以下統計維度：

### 使用統計

- **請求次數**：API 請求總量
- **趨勢圖表**：折線圖展示請求次數的時間變化趨勢

### 資源消耗

- **消耗額度**：已消耗的額度金額
- **消耗 Tokens**：Token 消耗總量
- **趨勢可視化**：折線圖展示額度 / Tokens 消耗趨勢

### 性能指標

- **平均 RPM**：每分鐘請求數
- **平均 TPM**：每分鐘 Token 數

### 模型數據分析

多維度分析模型使用情況：

- **消耗分佈**：不同時間段的消耗分佈（柱狀圖）
- **消耗趨勢**：模型消耗隨時間的變化趨勢（折線圖）
- **調用次數分佈**：各模型在總調用次數中的佔比（環形圖）
- **調用次數排行**：模型的調用次數排名（柱狀圖）

將鼠標懸停在圖表上可查看具體日期的詳細數據。

## 核心數據展示

| 模塊 | 數據項 | 說明 |
| --- | --- | --- |
| 用量概覽 | 近 24 小時消耗 | 最近一天的消耗金額 |
| 用量概覽 | 歷史使用情況 | 累計消耗金額 |
| 用量概覽 | 請求計數 | API 請求總量 |
| 用量概覽 | 剩餘額度 | 賬戶可用餘額 |
| 使用統計 | 請求次數 | API 請求總量 |
| 資源消耗 | 消耗額度 | 已消耗的額度金額 |
| 資源消耗 | 消耗 Tokens | Token 消耗總量 |
| 性能指標 | 平均 RPM | 每分鐘請求數 |
| 性能指標 | 平均 TPM | 每分鐘 Token 數 |

## 核心價值

1. **財務透明**：實時查看餘額、消耗歷史
2. **使用洞察**：量化 API 調用、Token 消耗、性能指標
3. **趨勢分析**：透過多維度圖表識別使用模式和異常
4. **模型分析**：瞭解各模型的調用頻率和消耗佔比
