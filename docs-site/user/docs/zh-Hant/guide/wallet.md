# 配額與充值

> 配額是平臺內部計費單位，消耗量 = 實際 Token 數 × 模型倍率。左側導航點擊「錢包」，或直接訪問 `/wallet`。

::: warning 合規提醒
充值、兌換碼和邀請鏈接適用於合法授權場景。使用時應符合授權範圍、上游服務條款、平臺規則和所在地法律法規要求。
:::

![錢包頁面](/imgs/wallet.jpeg)

支付方式由管理員在系統設置 → 支付設置中配置。

## 賬戶統計

頁面頂部實時展示賬戶的核心數據指標：

- **當前餘額**：賬戶可用餘額
- **總用量**：累計消耗金額
- **API 請求**：API 請求總量

## 充值方式

支援在線支付充值和兌換碼兩種方式增加賬戶配額。

| 充值方式 | 說明 |
| --- | --- |
| 兌換碼 | 輸入管理員生成的兌換碼，直接增加配額 |
| EPay | 國內聚合支付（支付寶、微信等） |
| Stripe | 國際信用卡支付 |
| Creem / Waffo | 國際支付平臺 |

## 在線支付充值

### 選擇充值金額

在「添加資金」區域選擇預設金額，或手動輸入自定義金額。

### 完成支付

1. 選擇支付方式（EPay / Stripe / Creem / Waffo）
2. 點擊「充值」按鈕，頁面跳轉至對應支付平臺
3. 在支付平臺完成付款後，自動跳回平臺，賬戶餘額更新

## 兌換碼充值

### 輸入兌換碼

1. 在「兌換碼」輸入框中粘貼或輸入管理員提供的兌換碼
2. 點擊「兌換額度」按鈕，系統驗證兌換碼有效性
3. 兌換成功後頁面提示獲得的配額數量，賬戶餘額同步更新

## 訂閱套餐

在錢包頁面的「訂閱套餐」區域可以查看和訂閱按週期購買的套餐。詳見[訂閱計劃](subscription.md)。

## 邀請返利

每個賬號都有唯一的邀請鏈接，當其他人透過你的邀請鏈接註冊成功時，你即可獲得邀請獎勵。

### 獲取邀請鏈接

在錢包頁面的「推薦計劃」區域，複製你的專屬邀請鏈接。

### 邀請獎勵機制

1. **註冊即返利**：被邀請人使用你的邀請鏈接註冊成功後，你（邀請人）會立即獲得系統配置的一筆「邀請獎勵配額」（一次性到賬）。
2. **轉入餘額**：點擊「轉入餘額」按鈕，即可將累計的返利配額轉入你的賬戶主餘額中進行使用。

## 核心數據展示

| 模塊 | 數據項 | 說明 |
| --- | --- | --- |
| 賬戶統計 | 當前餘額 | 賬戶可用餘額 |
| 賬戶統計 | 總用量 | 累計消耗金額 |
| 賬戶統計 | API 請求 | API 請求總量 |
| 推薦計劃 | 待確認收益 | 尚未劃轉到餘額的獎勵金額 |
| 推薦計劃 | 總收入 | 累計獲得的獎勵總額 |
| 推薦計劃 | 邀請人數 | 成功邀請的好友數量 |

## 使用場景

### 場景 1：使用兌換碼

1. 進入錢包頁面
2. 查看當前餘額和總用量
3. 使用兌換碼兌換額度（如有）

### 場景 2：邀請好友獲利

1. 複製邀請鏈接
2. 分享給好友或社交平臺
3. 好友註冊後，獲得獎勵
4. 定期查看收益統計
5. 將獎勵劃轉到賬戶餘額使用

## 核心價值

1. **餘額透明**：實時查看賬戶餘額和消耗情況
2. **記錄可查**：完整的消費記錄，便於對賬
3. **獎勵激勵**：邀請好友獲得額外收益
4. **收益管理**：清晰的收益統計和劃轉功能
