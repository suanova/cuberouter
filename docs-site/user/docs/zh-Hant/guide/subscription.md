# 訂閱計劃

> 訂閱是按週期購買的套餐，購買後在有效期內享受套餐內的配額或特權，適合有穩定用量需求的用戶。

訂閱套餐提供按週期計費的配額包，可選擇日、周、月等不同週期的套餐。

## 查看訂閱套餐

在「錢包」頁面的「訂閱套餐」區域，可以查看所有可購買的套餐，包含套餐名稱、價格、有效期、包含配額等資訊。

![訂閱套餐](/imgs/wallet.jpeg)

- **我的訂閱**：展示當前賬號生效中的訂閱及其有效期
- **優先錢包**：可選擇將某個訂閱的額度優先使用，避免與賬戶餘額混用
- **優先訂閱偏好**：已保存的偏好會在每次調用時優先生效

## 訂閱流程

### 瀏覽套餐資訊

在「訂閱套餐」區域瀏覽可用套餐，查看各套餐的價格、有效期和包含配額。

### 立即訂閱

1. 選擇要訂閱的套餐
2. 點擊「立即訂閱」按鈕
3. 按提示完成支付
4. 訂閱成功後，套餐配額立即生效，可在「我的訂閱」中查看

## 查看當前訂閱狀態

購買訂閱後，在「我的訂閱」區域可查看當前套餐的詳細資訊：

- 套餐名稱和有效期截止日期
- 套餐內剩餘配額

## 自動續費設置

可在此設置到期後是否自動續費。

::: tip 提示
訂閱配額與賬戶餘額是獨立計算的。當配置了「優先錢包 / 優先訂閱」時，調用會優先消耗訂閱內的配額，用盡後再回落到賬戶餘額。
:::
