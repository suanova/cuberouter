# 定價說明

> 瞭解 CubeRouter 的計費規則：按量計費與按次計費、配額如何消耗、如何核對賬單。

模型價格一覽及篩選瀏覽見[模型廣場](models-market.md)。

## 計費單位：配額

平臺以「配額」作為內部計費單位，所有餘額、消費、賬單均以配額顯示。

- 充值（在線支付 / 兌換碼 / 訂閱套餐 / 邀請返利）會增加賬戶配額
- 每次 API 調用按計費規則折算出消耗配額，從賬戶餘額中扣除

## 兩種計費類型

| 類型 | 計費方式 | 適用模型 |
| --- | --- | --- |
| **按量計費** | 按實際使用的 Token 數量計費 | 對話、補全、嵌入等文本類模型 |
| **按次計費** | 每次調用收取固定價格，不隨 Token 數量變化 | 圖像生成、影片生成、TTS 等任務類模型 |

### 按量計費

- **輸入價格**：輸入 Token 的單價（模型廣場中可切換 `/1M` 或 `/1K` 顯示單位）
- **輸出價格**：輸出 Token 的單價
- 實際消耗 = 輸入 Token 數 × 輸入單價 + 輸出 Token 數 × 輸出單價

部分模型還支援更細粒度的定價，在價格中體現為單獨單價：

- **緩存命中（讀取）**：命中提示緩存的 Token 單價通常遠低於普通輸入
- **緩存創建**：首次寫入緩存的 Token 單價通常略高於普通輸入
- **圖片 / 音頻**：多模態輸入輸出的 Token 按各自的單價計費

::: tip 價格顯示
模型廣場的價格以美元單價展示（如 `$3 / 1M`），最終扣減的配額數量由平臺按統一匯率折算。以使用日誌中顯示的實際扣減為準。
:::

### 按次計費

按次計費模型每次調用扣取固定配額，與請求內容長短無關。例如：

- 圖像生成：按「每次生成」計價，生成多張時按張數累加
- 影片生成：按固定時長或固定規格計價
- 語音合成 / 識別：按次或按時長計價

具體規格與價格以模型廣場中該模型的說明為準。

## 分組倍率

平臺支援按「分組」對用戶應用不同的計費倍率：

- 不同分組可能享有不同的折扣或倍率
- 創建 API 金鑰時選擇的分組決定該金鑰適用的計費倍率
- 實際消耗以使用日誌中的扣減金額為準

## 如何核對賬單

| 位置 | 查看內容 |
| --- | --- |
| 「使用日誌」 | 每次調用的輸入 / 輸出 Token 數與扣減配額 |
| 「任務日誌」 | 任務類調用（圖像、影片等）的狀態與消耗 |
| 「錢包」 | 賬戶當前餘額與充值記錄 |
| 「數據看板」 | 按模型 / 用戶維度的用量統計 |

如發現扣減金額與預期不符，可在使用日誌中查看該次調用的 Token 明細，並聯系管理員確認模型定價與分組倍率配置。

## 常見問題

### Q1: 為什麼日誌裡的 Token 數比模型廣場的價格頁面顯示的多？

按量計費的模型可能包含緩存 Token、多模態 Token 等，它們按各自單價單獨計費。使用日誌中的「輸入 / 輸出」是彙總值，明細可在日誌詳情中查看。

### Q2: 免費調用也會扣配額嗎？

只要調用了非免費模型，就會按計費規則扣取配額。管理員可配置部分模型或分組為免費，此時扣減為 0。

### Q3: 餘額不足會發生什麼？

餘額不足時，API 調用會被拒絕（返回 401 / 餘額不足錯誤），已開始的流式響應可能被中斷。請及時充值，或在「個人設置 → 通知設置」中開啟配額告警。
