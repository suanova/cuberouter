# 個人資料

> 管理賬號基本資訊、安全設置和第三方賬號綁定。登入後點擊右上角頭像，在下拉菜單中選擇「個人資料」，或直接訪問 `/profile`。

![個人設置](/imgs/profile.jpeg)

## 基本資訊

頁面頂部展示賬戶概覽：用戶名、用戶 ID、當前分組、當前餘額、總用量、API 請求數。

### 語言偏好

切換界面顯示語言，支援簡體中文、繁體中文、English、Français、Русский、日本語、Tiếng Việt 等，切換後自動保存。

## 第三方賬號綁定

將 GitHub、Discord 等第三方賬號與當前賬號綁定後，可直接用第三方賬號登入，無需輸入密碼。

支援的綁定平臺包括：Email、Phone、GitHub、Discord、LinuxDO、OIDC、Telegram、WeChat 及自定義 OAuth。

### 綁定第三方賬號

1. 在「賬戶綁定」區域找到要綁定的平臺
2. 點擊對應平臺的「綁定」按鈕
3. 頁面跳轉至該平臺的授權頁面，登入並點擊「授權」
4. 授權完成後自動跳回，綁定狀態變為「已綁定」
5. 已綁定的平臺可點擊「解綁」解除綁定

## 安全設置

### 更改密碼

點擊「更改密碼」，依次填寫當前密碼、新密碼、確認新密碼，點擊「確認修改」完成。

### 兩步驗證（2FA）

開啟兩步驗證後，每次登入時除密碼外還需輸入驗證器 App 中的動態碼，有效防止賬號被盜。

#### 開啟兩步驗證

1. 在手機上安裝驗證器 App（推薦 Google Authenticator 或 Microsoft Authenticator）
2. 在「安全」區域找到「兩步驗證」，點擊「啟用」
3. 用驗證器 App 掃描頁面上顯示的二維碼，App 中會出現一個 6 位動態碼
4. 將 App 中顯示的 6 位動態碼填入驗證框，點擊「確認啟用」
5. 系統顯示一組備用碼，請立即截圖或抄寫保存，用於無法使用驗證器時的緊急登入

::: warning 重要提醒
備用碼只顯示一次，關閉彈窗後無法再次查看。丟失備用碼且無法使用驗證器時，需聯繫管理員重置。
:::

### Passkey 無密碼登入

Passkey 支援使用設備指紋、面容識別或硬件安全金鑰登入，無需輸入密碼。

#### 註冊 Passkey

1. 在「安全」區域找到「Passkey 登入」
2. 點擊「啟用 Passkey」
3. 瀏覽器彈出系統驗證提示，按提示完成指紋、面容或安全金鑰驗證
4. 驗證通過後 Passkey 註冊完成，下次登入時可直接使用

### 登入會話

展示當前賬號的活躍登入會話，包括設備類型、IP 地址等資訊。可以：

- **登出**：退出指定會話
- **退出其他會話**：一次性退出除當前會話外的所有會話

## 通知設置

配置接收系統通知的方式，支援多種推送渠道。

- **通知郵箱**：設置接收通知的郵箱，留空則使用賬戶郵箱
- **通知方式**：可選 Webhook、Gotify、Bark Push、Telegram 等
- **配額告警閾值**：當餘額低於設定值時發送提醒
- **上游模型更新通知**：接收上游模型更新通知
- **消息優先級**：設置推送消息的優先級

以 Webhook 為例：

1. 選擇「Webhook」通知方式
2. 填寫 Webhook URL（接收通知的接口地址）
3. 可設置 Webhook Secret 用於簽名校驗
4. 點擊「保存設置」完成配置

Webhook 推送的數據格式為 JSON，包含事件類型、時間戳和詳細資訊。

## 價格設置

控制是否允許調用未設置價格的模型。

### 配置價格策略

- **接受未定價模型**：開啟後可調用所有模型，未定價模型按默認倍率計費；關閉則只能調用已設置價格的模型（推薦）

::: warning 重要提醒
允許未定價模型可能導致意外的高額消耗，建議保持默認的「拒絕未定價模型」設置。
:::

## IP 記錄設置

控制是否在日誌中記錄 API 調用的來源 IP 地址。

### 開啟 IP 記錄

- **記錄 IP 地址**：開啟後，在使用日誌頁面可以看到每次調用的來源 IP

IP 記錄有助於：

- 監控異常訪問
- 排查安全問題
- 分析流量來源

## 刪除賬戶

在「安全」區域底部可發起刪除賬戶操作。刪除前請確保已處理完畢餘額和金鑰，刪除後數據不可恢復。
