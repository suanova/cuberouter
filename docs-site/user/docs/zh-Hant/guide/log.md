# 使用日誌

> 查看每次 API 調用的詳細資訊，支援按時間、模型、令牌等條件過濾。左側導航點擊「使用日誌」，或直接訪問 `/usage-logs/common`。普通用戶只能看到自己的調用記錄。

![使用日誌](/imgs/log.jpeg)

## 查看使用記錄

日誌列表每行展示一次調用記錄，包含以下資訊：

| 列 | 說明 |
| --- | --- |
| **時間** | 調用時間 |
| **類型** | 流式 / 非流式 |
| **模型** | 調用的模型名稱 |
| **Token** | 輸入 / 輸出 Token 數 |
| **消耗** | 本次調用消耗的配額 |
| **首字** | 首字返回耗時 |
| **總耗時** | 請求總耗時 |
| **IP** | 發起請求的客戶端 IP |
| **渠道** | 實際處理請求的上游渠道 |
| **令牌名** | 使用的 API 金鑰名稱 |
| **操作** | 查看該次調用的詳細資訊 |

點擊「操作」列的「詳情」可查看該次調用的完整請求與響應內容。

## 搜索與過濾

### 設置過濾條件

1. 在日誌頁頂部的過濾工具欄中設置過濾條件：
   - **時間範圍**：選擇開始和結束日期
   - **類型**：按調用類型（流式 / 非流式）篩選
   - **模型名稱**：輸入模型名稱關鍵詞
   - **分組**：選擇 API 金鑰的分組
   - **令牌名 / 用戶名**：按金鑰名稱或用戶名篩選
   - **渠道 ID / 請求 ID / 上游請求 ID**：精確定位某次調用
2. 設置完成後點擊「查詢」，列表刷新顯示過濾結果；點擊「重置」可清除條件

### 查看過濾結果

設置完成後列表自動刷新顯示過濾結果。

## 用量彙總

列表頂部展示彙總統計：

- **用量**：篩選範圍內的總消耗金額
- **RPM**：每分鐘請求數
- **TPM**：每分鐘 Token 數

## 數據統計

### 訪問數據看板

左側導航點擊「數據看板」，或直接訪問 `/dashboard/models`，以折線圖或柱狀圖展示每日 API 調用量和配額消耗趨勢。將鼠標懸停在圖表上可查看具體日期的詳細數據。詳見[概覽與數據看板](dashboard.md)。
