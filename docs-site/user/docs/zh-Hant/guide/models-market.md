# 模型廣場

> 模型廣場是 CubeRouter 的模型展示和價格查詢中心，幫助快速找到目標模型並瞭解定價。

點擊頂部導航欄的「模型廣場」，或直接訪問 `/pricing`。

![模型廣場](/imgs/models-market.jpeg)

## 功能概述

- 📊 **模型瀏覽**：查看所有可用的 AI 模型
- 🔍 **智能篩選**：按分組、供應商、標籤、計費類型等多維度篩選
- 💰 **價格透明**：清晰展示每個模型的定價資訊
- 📋 **便捷複製**：一鍵複製模型名稱用於 API 調用

## 篩選面板

左側篩選面板提供多維度篩選條件，幫助快速找到目標模型。點擊「重置」可清空所有篩選條件，恢復默認視圖。

- **分組**：按 API 金鑰的分組篩選，查看當前金鑰可訪問的模型
- **供應商**：按模型供應商篩選（如 OpenAI、Claude、Gemini 等）
- **模型標籤**：按標籤篩選（如 chat、code、image 等）
- **定價類型**：按量計費 / 按次計費
- **端點類型**：按 API 端點類型篩選（Chat、Responses、Anthropic、Gemini、Rerank、圖片、嵌入、影片等）

## 模型展示區

### 搜索欄

在搜索框中輸入模型名稱關鍵字（快捷鍵 `⌘K`），列表自動顯示匹配的模型。

### 價格顯示

工具欄提供 `/1M` 與 `/1K` 切換，控制價格按每百萬或每千 Token 顯示。

每個模型展示以下資訊：

- **模型名稱**：完整的模型標識符（如 `deepseek-v4-flash`）
- **價格資訊**（按量計費模型）：輸入價格、輸出價格（如 `$0.1 / $0.1`）
- **價格資訊**（按次計費模型）：每次調用的固定價格
- **計費類型標籤**：按量計費 / 按次計費

### 視圖切換

- **卡片視圖**：以卡片形式展示模型（默認）
- **表格視圖**：以表格形式展示模型

## 計費類型說明

**按量計費**：

- 根據實際使用的 Token 數量計費
- 輸入 Token 和輸出 Token 價格不同
- 價格 = 輸入 Token × 輸入單價 + 輸出 Token × 輸出單價

**按次計費**：

- 每次調用固定價格，不受 Token 數量影響
- 價格 = 調用次數 × 單次價格

## 使用場景

### 查找特定模型

1. 打開模型廣場
2. 在搜索框輸入模型名稱關鍵字
3. 查看匹配的模型列表
4. 點擊複製按鈕獲取模型名稱

### 查看當前金鑰可用模型

1. 打開模型廣場
2. 按「分組」篩選出 API 金鑰對應的分組
3. 查看該分組可訪問的模型
4. 複製模型名稱用於 API 調用

### 比較模型價格

1. 按供應商或標籤篩選
2. 切換 `/1M` / `/1K` 價格顯示
3. 對比不同模型的輸入 / 輸出價格
4. 選擇性價比最高的模型

## 常見問題

### Q1: 如何快速找到我需要的模型？

使用篩選和搜索功能：先按標籤或供應商篩選，再在搜索框輸入關鍵字，快速定位目標模型。

### Q2: 按量計費和按次計費有什麼區別？

- **按量計費**：根據 Token 數量計費，價格 = 輸入價格 + 輸出價格
- **按次計費**：每次調用固定價格，不受 Token 數量影響

### Q3: 為什麼有些模型我看不到？

可能的原因：當前金鑰分組權限不足、模型已下線或維護中、篩選條件過濾掉了該模型。

### Q4: 如何查看模型的詳細價格？

在模型卡片中查看：按量計費顯示輸入 / 輸出價格，按次計費顯示單次價格，可切換 `/1M` / `/1K` 顯示單位。
