# 任務日誌

> 管理 Midjourney 繪圖、Suno 音樂生成等異步任務的狀態與結果。左側導航點擊「任務日誌」，或直接訪問 `/usage-logs/task`。

![任務日誌](/imgs/task.jpeg)

任務日誌頁提供兩個標籤頁：

- **繪圖日誌**：查看繪圖類任務（Midjourney 等）的記錄
- **任務日誌**：查看音樂生成等其他異步任務（Suno 等）的記錄

## 查看任務列表

任務列表展示所有已提交的異步生成任務，包含以下資訊：

- **提交時間**：任務提交的時間
- **任務 ID**：任務的唯一標識
- **耗時**：任務執行耗時
- **狀態**：任務的當前狀態
- **進度**：任務完成進度
- **詳情**：查看任務詳細結果

可透過「任務 ID」過濾條件篩選特定任務。

## 任務狀態說明

| 狀態 | 說明 |
| --- | --- |
| `PENDING` | 任務已提交，等待處理 |
| `IN_PROGRESS` | 任務正在生成中 |
| `SUCCESS` | 任務已完成，可查看結果 |
| `FAILURE` | 任務生成失敗，已自動退還配額 |
