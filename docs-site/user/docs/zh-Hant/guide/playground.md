# 遊樂場

> 遊樂場是 CubeRouter 提供的 AI 模型在線測試和對話工具，無需編寫代碼即可直接與模型對話，適合快速驗證金鑰和模型效果。

左側導航點擊「遊樂場」，或直接訪問 `/playground`。

![遊樂場頁面](/imgs/playground.jpeg)

## 功能概述

- 🎛️ **模型配置**：靈活配置模型參數，滿足不同場景需求
- 💬 **實時對話**：與 AI 模型進行實時對話測試
- 📊 **調試模式**：查看完整的請求和響應細節
- 💾 **配置管理**：保存、導入、導出模型配置

## 使用遊樂場

1. 在頁面頂部選擇要測試的模型
2. 在底部輸入框輸入消息內容，點擊發送
3. 對話區域顯示模型的回覆結果

![遊樂場對話示例](/imgs/playground.jpeg)

回覆下方顯示響應時間，並提供以下操作按鈕：

- **複製**：一鍵複製消息內容
- **顯示源碼**：查看原始 Markdown 內容
- **重新生成**：重新生成當前回覆
- **編輯**：編輯已發送的消息
- **刪除**：刪除當前消息

頁面還提供「入門提示詞」快捷按鈕（分析數據、總結文本、代碼、獲取建議），方便快速開始測試。

## 參數設置

點擊輸入框旁的「參數」按鈕，可打開參數設置彈窗，配置模型參數。只有啟用的參數會隨請求發送。

![參數設置](/imgs/playground-params.jpeg)

### Temperature（溫度）

- 控制輸出的隨機性和創造性
- 範圍：0.0 - 2.0，默認值：0.7
- 低溫度（0.0 - 0.3）：輸出更確定、更一致，適合代碼生成
- 高溫度（0.8 - 2.0）：輸出更隨機、更有創意，適合創意寫作

### Top P（核採樣）

- 控制詞彙選擇的多樣性
- 範圍：0.0 - 1.0，默認值：1.0
- 通常不需要調整，建議優先調整 Temperature

### Frequency Penalty（頻率懲罰）

- 減少重複詞彙的出現頻率
- 範圍：-2.0 - 2.0，默認值：0
- 正值：懲罰已出現的詞彙，避免重複

### Presence Penalty（存在懲罰）

- 鼓勵討論新話題
- 範圍：-2.0 - 2.0，默認值：0
- 正值：鼓勵討論新話題

### Max Tokens（最大輸出長度）

- 控制輸出的最大 Token 數量
- 默認值：4096
- 注意模型的最大 Token 限制

### Seed（隨機種子）

- 用於復現相同的輸出結果
- 留空則每次輸出可能不同

## 參數配置建議

**代碼生成**：

- Temperature：0.2
- Top P：0.5
- Frequency Penalty：0.0
- Presence Penalty：0.0

**創意寫作**：

- Temperature：0.9
- Top P：0.9
- Frequency Penalty：0.3
- Presence Penalty：0.6

**問答對話**：

- Temperature：0.7
- Top P：1.0
- Frequency Penalty：0.0
- Presence Penalty：0.0

## 使用場景

### 快速測試模型

1. 打開遊樂場
2. 選擇要測試的模型
3. 輸入問題
4. 查看模型回覆
5. 調整參數重新測試

### 調整生成效果

1. 輸入問題，查看初始回覆
2. 不滿意時調整參數：
   - 提高 Temperature 增加創意
   - 降低 Temperature 提高精確性
   - 調整 Top P 控制多樣性
3. 重新生成回覆

## 核心價值

1. **快速測試**：無需編寫代碼即可測試模型效果
2. **參數調優**：直觀調整參數找到最佳配置
3. **實時反饋**：即時看到參數變化的影響
4. **配置管理**：保存、分享、導入配置
