# 故障排除

本指南提供常見問題的排查步驟和解決方案，幫助您快速定位和解決問題。

> 錯誤提示可能因語言設置顯示為中文或英文，以下按錯誤類型歸納。

## API 金鑰無效（Invalid API Key）

請求返回 401 或提示金鑰無效時：

1. 檢查 API Key 是否正確複製，前後不要有多餘空格或換行
2. 確認金鑰未被禁用、刪除或已過期（在「API 金鑰」頁查看狀態）
3. 檢查請求頭格式：`Authorization: Bearer sk-xxx`（`Bearer` 後有一個空格）
4. 確認該金鑰所在分組擁有目標模型的使用權限

## 餘額不足（Insufficient Quota）

請求返回 403 或提示額度不足時：

1. 在「錢包」查看當前餘額
2. 餘額不足時進行充值（在線支付或兌換碼）
3. 若使用了訂閱套餐，確認訂閱額度與有效期

::: tip 優先扣費順序
賬戶同時有餘額和訂閱額度時，平臺按配置優先扣除其中一種，可在「訂閱計劃」中瞭解扣費優先級。
:::

## 觸發限流（Rate Limit）

請求返回 429 或提示頻率過高時：

1. 降低請求頻率，或為重試增加退避間隔
2. 檢查是否為上游服務商限流（部分模型廠商對併發有限制）
3. 確認金鑰所在分組的限流配置，必要時聯繫管理員調整

## 模型不存在（Model Not Found）

請求返回 404 或提示模型不存在時：

1. 檢查模型名稱是否完全正確（區分大小寫，不要添加廠商前綴）
2. 在「模型廣場」確認該模型當前是否可用
3. 確認您的分組有該模型的使用權限

## 請求超時或無響應

1. 檢查網路連接與 API Base URL 配置
2. 對於長耗時任務（影片生成等），改用異步任務方式並輪詢任務狀態
3. 增大客戶端請求超時時間
4. 仍無法解決時聯繫管理員

## 流式響應中斷

1. 檢查客戶端是否正確處理了 `finish_reason` 與流結束標記
2. 確認網路穩定，避免長連接被中間設備斷開
3. 查看「使用日誌」中該次請求的完成狀態與 Token 明細

## 仍無法解決

請透過[聯繫支援](contact.md)提交問題，並附上：

- 使用日誌中的請求 ID
- 完整的錯誤響應內容
- 復現請求的關鍵參數（脫敏後）
