# 版本日誌

本文檔記錄 CubeRouter 的版本更新歷史、新功能、改進和已知問題。

## 最新版本

### v1.0.0（2026-03）

首次發佈。CubeRouter 是一款企業級 AI 模型聚合與中轉平臺，提供統一的 OpenAI 兼容 API 接口，支援 40+ AI 服務商及企業私有模型，具備智能路由、計費與配額管理等功能。

#### 核心功能

- **多模型支援**：支援 OpenAI、Claude、Gemini、DeepSeek 等 40+ AI 服務商的模型，並支援接入企業私有模型
- **智能路由**：多渠道加權分發、失敗自動重試、用戶級模型限流
- **計費系統**：按量計費與按次計費，支援緩存 / 多模態 Token 的差異化計價
- **配額與訂閱**：統一的配額賬戶，支援在線支付、兌換碼充值與訂閱套餐
- **金鑰管理**：API 金鑰支援分組、模型限制、IP 白名單、過期時間
- **使用與任務日誌**：按次調用記錄與圖像 / 影片等異步任務記錄
- **數據看板**：用量、消耗與性能的多維統計
- **多語言界面**：支援中 / 英 / 日 / 法 / 俄 / 越 6 種語言
- **安全能力**：兩步驗證（2FA）、Passkey、多方式 OAuth 登入

#### 客戶端與工具

- 兼容 OpenAI 協議，可接入 Claude Code、opencode、OpenClaw 等工具
- 站內「遊樂場」支援在線測試模型與參數調試
