# 聯繫支援

在使用 CubeRouter 服務時，如果你有任何問題或建議，歡迎聯繫平臺管理員。

## 聯繫渠道

- **站內公告**：管理員公告與常見問題會在控制台「概覽」頁展示
- **社區 / 群組**：以站點公告中公佈的渠道為準
- **私有化部署**：直接聯繫為您的服務提供部署支援的管理員

> 聯繫時請儘量提供：請求 ID、錯誤響應內容、復現步驟，以便快速定位問題。
