# 常見問題

以下是用戶最常詢問的問題和解答，幫助您快速解決常見問題。

## Q1: CubeRouter 是什麼？

CubeRouter 是一個 AI 模型聚合與中轉平臺，提供統一的 OpenAI 兼容 API 網關來訪問多種 AI 模型，包括 OpenAI GPT 系列、Anthropic Claude、Gemini、DeepSeek 等 40+ 服務商的模型。

## Q2: CubeRouter 與直接使用模型廠商 API 有什麼區別？

主要區別：

- **統一接口**：透過一個 API 地址和一套金鑰訪問多個廠商的模型
- **統一計費**：所有調用折算為配額，一處充值、統一對賬
- **多渠道路由**：同一模型可配置多個上游渠道，自動負載均衡與故障重試
- **企業級功能**：完整的用戶管理、分組、限流、日誌與監控

## Q3: 支援哪些模型？

平臺支援 40+ 服務商的模型，具體可用模型及價格以站內「模型廣場」為準。

## Q4: 支援哪些客戶端工具？

CubeRouter 的 API 兼容 OpenAI 協議，可直接接入 Claude Code、opencode、OpenClaw 及各類 SDK。詳見[快速開始](../getting-started/quick-start.md)。

## Q5: 如何計費？

分為按量計費（按 Token 計費）和按次計費（每次調用固定價格）兩種，詳見[定價說明](../guide/pricing.md)。

## Q6: 金鑰丟了怎麼辦？

創建金鑰時完整金鑰僅顯示一次。若金鑰丟失，可在「API 金鑰」頁刪除舊金鑰並創建新金鑰；若金鑰懷疑洩露，可直接禁用或刪除該金鑰。

## Q7: 數據安全如何保障？

- 全站支援 HTTPS 傳輸加密
- 金鑰支援 IP 白名單限制
- 支援私有化自託管部署，數據不出本地
- 個人敏感操作支援兩步驗證（2FA）與 Passkey

## Q8: 服務響應慢怎麼辦？

排查步驟：

1. 檢查本地網路連接
2. 確認 API Base URL 配置正確（避免多餘的 `/v1` 路徑）
3. 嘗試更換模型或稍後重試
4. 仍無法解決時聯繫管理員，提供使用日誌中的請求 ID
