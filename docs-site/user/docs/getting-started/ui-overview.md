# 界面概览

> 欢迎使用 CubeRouter！本指南将带你快速了解平台界面。

## 平台界面整体介绍

CubeRouter 采用现代化的响应式设计，界面简洁直观。登录后的控制台由**左侧边栏**和**主内容区域**组成；公开页面（首页、模型广场等）由**顶部导航栏**和主内容区域组成。

![平台首页](/imgs/home.jpeg)

## 顶部导航栏

![控制台界面](/imgs/dashboard.jpeg)

顶部导航栏包含 Logo、导航项和右侧功能区域。导航项由站点配置决定，默认通常包括：

- **Logo**：点击跳转平台首页，展示产品介绍、使用步骤和 API 调用示例
- **模型广场**：浏览可用模型列表和定价信息
- **排行榜**：查看模型用量排行
- **关于**：了解更多关于平台的信息

## 顶部右侧区域

- **消息通知**：当有未读系统公告或应用内通知时，图标上方显示红色数字徽章，点击后可查看系统公告和账户通知
- **语言切换**：支持简体中文、繁體中文、English 等语言，切换后自动保存
- **主题切换**：支持浅色模式、深色模式和跟随系统的自动模式以及颜色等
- **用户区域**：
  - 未登录状态：显示「登录」按钮
  - 已登录状态：显示用户头像（首字母）和用户名，点击展开下拉菜单：
    - **个人资料**：修改个人信息、安全设置等
    - **钱包**：查看余额和充值
    - **退出**：退出当前账户

## 左侧边栏（控制台）

登录进入控制台后，左侧边栏提供以下功能入口：

| 菜单 | 说明 |
| --- | --- |
| 游乐场 | 在线测试模型对话效果 |
| 概览 | 账户用量概览、API 信息、公告和常见问答 |
| 数据看板 | 调用量、Token 消耗、性能指标等多维度统计 |
| API 密钥 | 创建和管理调用 API 的密钥 |
| 使用日志 | 查看每次 API 调用的详细记录 |
| 任务日志 | 查看绘图、音乐生成等异步任务 |
| 钱包 | 余额管理、充值、兑换码和邀请返利 |
| 个人资料 | 个人设置等 |

> 不同角色的用户看到的菜单不同：管理员和运营用户还会看到渠道管理、模型管理、用户管理、系统设置等额外菜单。

## 概览页

登录后的默认页面是「概览」，展示：

![概览页](/imgs/dashboard.jpeg)

- **设置引导**：创建 API 密钥、添加额度、发送请求的三步引导
- **用量概览**：近 24 小时消耗、历史使用情况、请求计数、剩余额度
- **API 信息**：API 地址、文档入口
- **公告**：最新系统公告
- **常见问答**：常见问题展开查看
- **运行时间**：服务性能指标
