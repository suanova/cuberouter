# 注册与登录

> 支持账号密码注册，以及多种第三方 OAuth 一键登录。首次使用请先完成注册。

## 注册

### 注册流程

1. 访问首页，点击「获取 API Key」按钮，或直接访问 `/sign-up`

![注册页面](/imgs/register.jpeg)

2. 填写注册信息：
   - **用户名**：登录用户名，建议使用英文，用户名一旦注册不可修改
   - **邮箱**：用于接收验证码（必填）
   - **密码**：登录密码（8-20 位，建议包含字母和数字）
   - **手机号**（可选）：部分平台启用手机验证时需要填写
3. 点击「注册」完成账号创建

::: tip 推荐做法
- 开启[两步验证](../guide/personal-setting.md#两步验证2fa)，为账户添加额外的安全层
- 定期更换密码，建议每 3-6 个月更换一次
- 谨慎使用公共网络，避免在公共 WiFi 下登录重要账户
- 保护账户信息，不向他人透露账户密码、验证码
:::

## 登录

### 账号密码登录

1. 访问首页，点击右上角「登录」按钮，或直接访问 `/sign-in`

![登录页面](/imgs/login.jpeg)

2. 输入用户名和密码，点击「登录」完成登录

### 第三方 OAuth 登录

如平台已配置第三方登录，点击登录页下方对应平台的图标（GitHub、Discord、LinuxDO、Telegram、OIDC 等），跳转至第三方授权页面完成授权后自动登录。

### 忘记密码

忘记密码时，点击登录页的「忘记密码」链接，输入注册邮箱后系统会发送重置链接，点击链接设置新密码，原密码随即失效。

## 支持

如果在注册或登录过程中遇到任何问题，可前往[联系支持](../support/contact.md)寻求帮助。
