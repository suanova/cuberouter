# 故障排除

本指南提供常见问题的排查步骤和解决方案，帮助您快速定位和解决问题。

> 错误提示可能因语言设置显示为中文或英文，以下按错误类型归纳。

## API 密钥无效（Invalid API Key）

请求返回 401 或提示密钥无效时：

1. 检查 API Key 是否正确复制，前后不要有多余空格或换行
2. 确认密钥未被禁用、删除或已过期（在「API 密钥」页查看状态）
3. 检查请求头格式：`Authorization: Bearer sk-xxx`（`Bearer` 后有一个空格）
4. 确认该密钥所在分组拥有目标模型的使用权限

## 余额不足（Insufficient Quota）

请求返回 403 或提示额度不足时：

1. 在「钱包」查看当前余额
2. 余额不足时进行充值（在线支付或兑换码）
3. 若使用了订阅套餐，确认订阅额度与有效期

::: tip 优先扣费顺序
账户同时有余额和订阅额度时，平台按配置优先扣除其中一种，可在「订阅计划」中了解扣费优先级。
:::

## 触发限流（Rate Limit）

请求返回 429 或提示频率过高时：

1. 降低请求频率，或为重试增加退避间隔
2. 检查是否为上游服务商限流（部分模型厂商对并发有限制）
3. 确认密钥所在分组的限流配置，必要时联系管理员调整

## 模型不存在（Model Not Found）

请求返回 404 或提示模型不存在时：

1. 检查模型名称是否完全正确（区分大小写，不要添加厂商前缀）
2. 在「模型广场」确认该模型当前是否可用
3. 确认您的分组有该模型的使用权限

## 请求超时或无响应

1. 检查网络连接与 API Base URL 配置
2. 对于长耗时任务（视频生成等），改用异步任务方式并轮询任务状态
3. 增大客户端请求超时时间
4. 仍无法解决时联系管理员

## 流式响应中断

1. 检查客户端是否正确处理了 `finish_reason` 与流结束标记
2. 确认网络稳定，避免长连接被中间设备断开
3. 查看「使用日志」中该次请求的完成状态与 Token 明细

## 仍无法解决

请通过[联系支持](contact.md)提交问题，并附上：

- 使用日志中的请求 ID
- 完整的错误响应内容
- 复现请求的关键参数（脱敏后）
