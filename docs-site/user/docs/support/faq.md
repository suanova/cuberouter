# 常见问题

以下是用户最常询问的问题和解答，帮助您快速解决常见问题。

## Q1: CubeRouter 是什么？

CubeRouter 是一个 AI 模型聚合与中转平台，提供统一的 OpenAI 兼容 API 网关来访问多种 AI 模型，包括 OpenAI GPT 系列、Anthropic Claude、Gemini、DeepSeek 等 40+ 服务商的模型。

## Q2: CubeRouter 与直接使用模型厂商 API 有什么区别？

主要区别：

- **统一接口**：通过一个 API 地址和一套密钥访问多个厂商的模型
- **统一计费**：所有调用折算为配额，一处充值、统一对账
- **多渠道路由**：同一模型可配置多个上游渠道，自动负载均衡与故障重试
- **企业级功能**：完整的用户管理、分组、限流、日志与监控

## Q3: 支持哪些模型？

平台支持 40+ 服务商的模型，具体可用模型及价格以站内「模型广场」为准。

## Q4: 支持哪些客户端工具？

CubeRouter 的 API 兼容 OpenAI 协议，可直接接入 Claude Code、opencode、OpenClaw 及各类 SDK。详见[快速开始](../getting-started/quick-start.md)。

## Q5: 如何计费？

分为按量计费（按 Token 计费）和按次计费（每次调用固定价格）两种，详见[定价说明](../guide/pricing.md)。

## Q6: 密钥丢了怎么办？

创建密钥时完整密钥仅显示一次。若密钥丢失，可在「API 密钥」页删除旧密钥并创建新密钥；若密钥怀疑泄露，可直接禁用或删除该密钥。

## Q7: 数据安全如何保障？

- 全站支持 HTTPS 传输加密
- 密钥支持 IP 白名单限制
- 支持私有化自托管部署，数据不出本地
- 个人敏感操作支持两步验证（2FA）与 Passkey

## Q8: 服务响应慢怎么办？

排查步骤：

1. 检查本地网络连接
2. 确认 API Base URL 配置正确（避免多余的 `/v1` 路径）
3. 尝试更换模型或稍后重试
4. 仍无法解决时联系管理员，提供使用日志中的请求 ID
