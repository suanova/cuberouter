# 版本日志

本文档记录 CubeRouter 的版本更新历史、新功能、改进和已知问题。

## 最新版本

### v1.0.0（2026-03）

首次发布。CubeRouter 是一款企业级 AI 模型聚合与中转平台，提供统一的 OpenAI 兼容 API 接口，支持 40+ AI 服务商及企业私有模型，具备智能路由、计费与配额管理等功能。

#### 核心功能

- **多模型支持**：支持 OpenAI、Claude、Gemini、DeepSeek 等 40+ AI 服务商的模型，并支持接入企业私有模型
- **智能路由**：多渠道加权分发、失败自动重试、用户级模型限流
- **计费系统**：按量计费与按次计费，支持缓存 / 多模态 Token 的差异化计价
- **配额与订阅**：统一的配额账户，支持在线支付、兑换码充值与订阅套餐
- **密钥管理**：API 密钥支持分组、模型限制、IP 白名单、过期时间
- **使用与任务日志**：按次调用记录与图像 / 视频等异步任务记录
- **数据看板**：用量、消耗与性能的多维统计
- **多语言界面**：支持中 / 英 / 日 / 法 / 俄 / 越 6 种语言
- **安全能力**：两步验证（2FA）、Passkey、多方式 OAuth 登录

#### 客户端与工具

- 兼容 OpenAI 协议，可接入 Claude Code、opencode、OpenClaw 等工具
- 站内「游乐场」支持在线测试模型与参数调试
