# 联系支持

在使用 CubeRouter 服务时，如果你有任何问题或建议，欢迎联系平台管理员。

## 联系渠道

- **站内公告**：管理员公告与常见问题会在控制台「概览」页展示
- **社区 / 群组**：以站点公告中公布的渠道为准
- **私有化部署**：直接联系为您的服务提供部署支持的管理员

> 联系时请尽量提供：请求 ID、错误响应内容、复现步骤，以便快速定位问题。
